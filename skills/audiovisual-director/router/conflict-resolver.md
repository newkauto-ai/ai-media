# Conflict Resolver

Apply authority by decision domain, not one global priority.

Hard outcomes:

- `FLAG-CONFLICT`: a style or production convenience would change frozen content semantics.
- `STYLE-CONTENT-MISMATCH`: the selected style is incompatible; recommend a different profile or request explicit forced use.
- `UPSTREAM-CONSTRAINT-LATE`: a content rule arrived after script freeze.
- `UNRESOLVED`: required decision must return to the user/upstream owner.

Allowed cost reductions, in order: merge Audiovisual Beats, merge scenes, remove secondary characters, reuse assets, move secondary information to narration, reduce action complexity, reduce effects.

Never reduce cost first by deleting the Hook, core evidence, Reveal, or Content Thesis.
