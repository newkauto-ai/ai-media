# Module 2 — Character & Voice Bible

Define each required character across visual, voice, and performance identity.

Required fields: `character_id`, `name`, `narrative_role`, `visual`, `voice`, `performance`, and field-level provenance.

Visual identity covers apparent age, body, face, hair, costume, palette, materials, accessories, silhouette, and prohibited changes. Voice covers gender expression, apparent age, pitch, timbre, resonance, tempo, articulation, emotional baseline/range, accent, and prohibited traits. Performance covers posture, gesture, facial behavior, and motion energy.

Source-defined Canon stays locked. Missing voice fields remain `null` at source level; add a separate `runtime_recommended` voice only when production needs a proposal.
