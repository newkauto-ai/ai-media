# Audiovisual Direction Package — Human Review

## Stage 1 visual test review

After the Stage 0 script-architecture approval, show only the following before the next gate:

- `Global visual DNA`
- Image prompt — `主角`
- Image prompt — `场景`
- Image prompt — `Key Frame`

These are the minimum LookDev test prompts. They are not generated-image claims or paid-generation
approval. Stop and request `确认第2点（批准视觉测试）` before displaying the complete package.

## 1. Scope and semantic locks

List project/script IDs, Topic Thesis, Hook, Reveal, conclusion, factual claims, style inputs, and current overrides.

## 2. Style resolution

Show compatibility result, loaded/routed/ignored modules, provenance, and unresolved conflicts.

## 3. Audiovisual blueprint

Summarize global visual DNA, required visual domains, camera, performance, sound, voice, and music identity.

## 4. Character and voice

Use one compact table per character. Distinguish source-defined and runtime-recommended fields.

## 5. Assets

List reusable characters, scenes, props, special assets, and risks.

## 6. Audiovisual Beats

Use an 8–12 row table with story function, script reference, visual/action, performance, sound/music, continuity, and production risk.

## 7. Music

Include Music Brief and Suno Prompt as separate sections.

## 8. Continuity and Skill 4 handoff

List expected states, complexity, highest-risk Beats, generation priority, validation order, and the model-independent LookDev Test Spec.

Do not include executable image/video prompts or generated-asset claims.
