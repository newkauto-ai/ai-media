# Scene and Clip Planner

Create a Scene when location, time, world state, character set, costume/state, or lighting logic materially changes. Pack adjacent ADP Beats into a Clip only when character, action, emotion, and space are continuous and the Adapter supports the total duration.

For generative video, Clip is the generation unit. It may contain one or more Shots. A Shot is a real cut; a Camera Beat is a movement phase inside a Shot. Record all four identifiers separately. Use 6–14 seconds for an initial generative Clip unless a configured Adapter supports a different stable range. If a complex generated multi-shot plan fails, split it into two continuous Clips with a Resume Keyframe rather than many independent short Shots. A local Remotion assembly Shot is an edit/assembly unit instead: it follows confirmed narration and editorial intent and is not rejected for missing a generative Video Prompt or for falling outside 6–14 seconds.

For each Scene, emit structured `coverage_id`, `axis_group_id`, `view_direction`, `shot_size`, `visible_zone_ids`, and `reveals_new_space` inputs. The last field is an approved structured/semantic/human assessment, not a keyword result. Same-axis shot-size changes may reuse the same coverage; a new Scene Setting requirement is derived only when a reused Scene has at least two materially different reviewed coverage entries.

For VOX Remotion local assembly, first use the VOX Poster Shot Planner. Preserve the ADP Beat as the high-level function and project one or more Poster Shots with `poster_shot_id`, `source_beat_id`, open-vocabulary `shot_role`, `poster_archetype`, `stable_poster_state`, `pilot_design_route`, `motion_route`, `adjacent_shot_difference`, and optional `historical_visual_mode`. Long or dense Beats may use establish plus detail/evidence, but two Shots are never mandatory.

Plan Beat, editing Shot, source Poster and within-Shot semantic event separately. A long Beat can use several Shots with different Posters; Shots across Beats can reference one exact Poster source without copying it. Keep the scalar `source_beat_id` on each Shot and absolute time; shared source, continuous camera/parent group and narration may cross a logical boundary without an extra visible cut or new generation. Sentence/SRT boundaries and a fixed number of seconds are not sufficient reasons to split. Each changed layout, critical-text visibility, crop or exposure has its own Review scope even when source pixels are shared.

Also project the minimum existing Scene/Shot/asset records needed by real consumers: `information_goal`, `key_layout_states`, `primary_attention_target`, `semantic_end_state`; one `pilot_design_route` from `hero_key_art` or `production_reconstructable`; optional `historical_visual_mode` from `hero_cinematic`, `editorial_explainer`, or `atmospheric_historical`; one later `decomposition_decision` from `keep_whole`, `partial_decomposition`, `full_element_assembly`, or `rebuild_locally`; `poster_spec` with visual hierarchy, primary/secondary elements, background/foreground systems, reading path, text safe area, `critical_text_owner: remotion`, `critical_text_realization`, `generate_text_in_image: false`, bounded `background_plate_strategy`, `cut_paper_outline_runtime_style`, stable-state ref, route-specific Review ref, Poster Readiness Review ref, and applicable Static Reconstruction evidence ref; `motion_plan` with route, open-descriptive camera intent/phases, target-specific element motion, and conditional `why_not_remotion`; per-element independent `z_order`, position, size, placement anchor, facing direction/target; time-bounded face/hand/prop/evidence-text protection regions, caption safe area, and any intentional crop reason; camera start, reading target, camera phases; layer enter/settle/emphasize/exit events; and absolute narration plus caption/SFX bindings. Layer count is selected by the Shot. The optional group-portrait recipe is background/back row/primary/foreground, while maps, infographics, and comparisons may use other structures. `primary/secondary/tertiary` is narrative weight only and never auto-assigns z-order, size, entrance, opacity, motion amplitude, or a shared Y coordinate.

For Historical VOX, keep `historical_visual_mode`, `pilot_design_route`, `decomposition_decision`, and `motion_route` as four independent decisions. Project the chosen mode into the existing `poster_spec`; do not create a new historical Scene/Shot schema. Require historical subject + evidence/context + editorial explanation, an explanatory purpose for every map/route/timeline, Remotion-owned labels and critical text, clean visible Alpha for independently moving people, preserved approved source outlines or runtime outline only when needed, and Project Visual Bible refs for era/person/costume/terrain/project-specific details. Non-historical Shots omit the field or use `null` and preserve v1.9 behavior.

For selected `oriental_pastoral_cinematic_lifestyle` craft content, project the Profile's optional poetic-craft montage fields into the existing Scene/Shot plan; do not create another Manifest, Gate, state owner, or planner. Activate only from current project, Script, ADP, or human evidence that the content is light craft, intangible heritage, folk making, handwork, light cooking, or light manufacturing—keywords alone are examples, not proof. Classify each applicable Shot as exactly one `pastoral_craft_shot_type`: `atmosphere_shot`, `process_detail_shot`, or `progression_shot`; non-craft Shots omit the field or use `null`.

Use this existing-plan projection:

```yaml
pastoral_craft_shot_type: atmosphere_shot | process_detail_shot | progression_shot | null
breathing_shot_note: string | null
prior_process_state_ref: string | null
current_process_state: string | null
completion_delta: string | null
match_cut_or_visual_echo: string | null
```

An `atmosphere_shot` is a formal narrative node and records how it establishes region/space, changes breathing, carries emotion, creates contrast/visual echo, or supplies aftertaste; it is not scenery filler. A `process_detail_shot` shows one credible bounded local action and may end after approach, contact, light placement, arranging, stable touch, or minor material response without pretending to complete a tutorial. A `progression_shot` binds a prior state, current state, and specific visible `completion_delta`; it must not imply magic growth, full-frame morphing, or unsupported instant completion. Preserve the v1.1 fact and material-state chain across Shots: the previous result still becomes the next input.

Design the rhythm adaptively from the current narrative intent, process complexity, material-state change, information density, human/space relationship, music or emotional arc, breathing need, and visible completion delta. Do not apply a fixed shot ratio, default sequence, or mandatory human/process/atmosphere alternation. Insert an `atmosphere_shot` only when it has a named narrative function, and insert a `progression_shot` when meaningful progress becomes visible. Record how the chosen sequence serves this specific content and avoids five or six consecutive same-function craft macros or reuse of a generic template. Jiangnan, water-town, Hanfu, embroidery, tea, and similar examples require current project grounding and are never injected as universal Style constants.

Select the Pilot route before image generation. `hero_key_art` may retain a fused complete scene and is not required to pass reconstructability checks. `production_reconstructable` must be designed as a coherent poster with separable typography, directional, decorative, and context groups and must pass the five Production Reconstructability findings before decomposition. If the real Production Pilot is visually strong but over-fused, recommend Hero reclassification and use existing salvage/reuse instead of rectangular cropping.

Choose minimum sufficient decomposition. A high-quality hero poster may remain whole or lightly decomposed; a VOX editorial body may mix whole posters, local graphics, partial decomposition and a small number of hero posters. Full element assembly is not a style-quality score and torn-paper treatment is not mandatory on every Shot.

For `partial_decomposition`, `full_element_assembly`, `rebuild_locally`, or any changed whole-poster crop/text/layout, bind a no-motion reconstruction to the existing Poster Readiness / `previsualization_storyboard` Review Result before compiling motion. Preserve composition, hierarchy, focal weight, negative space, palette and typography character without requiring pixel-perfect equality. Derive plate exposure from approved motion and recover only exposed bounds plus justified margin; do not generate a full background mechanically.

Critical text stays Remotion-owned and uses only `remotion_native_text`, `verified_typography_svg`, or `verified_typography_png`. Verified typography assets retain Remotion placement/timing and require glyph/fact/Alpha/delivery-size/rights checks. Hero Typography must preserve its approved display character instead of falling back to ordinary CSS. Historical/cultural hero numerals default to locale-appropriate written display while modern data visualization may retain Arabic numerals; bind source value and confirm semantic equivalence.

Derive the Production Asset Set only from assets referenced by at least one current approved Poster Shot. Record `reuse_count`, `used_by_poster_shots`, `production_priority`, and `implementation_route`; production eligibility does not grant a provider call or Cost Gate. Unused Candidate Asset Plan entries remain ungenerated.

When a real generated asset misses its original Shot, record an existing asset/QA salvage disposition after checking `later_beat`, `hero_poster`, `cover`, `title_card`, `detail_crop`, `background`, and `transition`; use `reject` only after those candidates are evidenced unsuitable.

Validate key static layouts before in-motion occlusion. Use pose-appropriate foot or base anchors for standing, seated, stepped, and back-row subjects. Intentional partial occlusion and declared close-up crop are legal when the currently protected face, hand, prop, evidence text, and caption regions remain readable. Derive scene-local frame and element-delayed frame exactly once from the global frame; procedural noise uses fixed seeds.

For a structure-locked reference remake, preserve the ordered ADP mapping and function, but do not
equate a reference unit with a generation Clip. Split or merge only for current Adapter capability,
continuity, or editability, and keep requirement-to-Clip refs. Default generation duration is not
evidence for final edit duration.

For a VOX Beat, bind confirmed Master Audio and the project's approved SRT/alignment source as read-only absolute time before scheduling motion. Build semantic events from actual text/audio evidence; do not claim word-level sync without word-level evidence. Identify setup, pause, core action and result hold, then choose speed and camera from information gain. Fixed view, semantic focus, travel, reframe and 2.5D remain options; 2.5D needs separable layers, connection ownership, exposure coverage and extreme-crop checks. A route/process Shot explains at least one actual location, start/end, sequence, range, relation or change. Preserve whole-film absolute time; do not sum rounded independent Pilot durations.

## Layered micro-animation

For VOX, after evidenced background recovery and usable separation, actively consider differential scale/translation rather than using layers only for entrances. Distinguish shared camera/group motion from relative layer motion. Preserve parent anchors and ground/hand/prop/string/flag/map-label connections; attached typography, outline and shadow follow the owning group, while independent conclusions may remain stable. One fixed pivot does not prove all contact edges safe. Record common/relative movement, exposure limits and ending intent in existing motion timing/phases, not new required fields.

Choose `continue_to_last_visible_frame` or an intentional reading hold according to approved intent. The former must remain perceptibly moving through the whole tail and last visible frame: no early endpoint or ease-out visual stall. A declared reading hold remains valid; never impose continuous motion on every Shot. Check margin, occlusion, source crop edges and extremes before motion. Judge relative movement at target viewing size; if too weak, adjust differential amplitude/direction/anchor/timing rather than merely increasing global zoom. Parameters are Shot-specific, and unsupported hidden anatomy requires reduced motion or a fused group.
