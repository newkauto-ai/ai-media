# Asset Prompt Compiler

Follow the [Executable Prompt Contract](../contracts/executable-prompt-contract.md) v1.3. Resolve source locks, reference responsibilities, seven decision statuses, type/Adapter triggers, and conflicts before rendering one frozen type-specific template. Emit an internal `image_prompt_spec`, an external `executable_prompt`, a sentence-level clause map, and a reviewable `call_package`; never serialize raw spec YAML to a model.

The first effective sentence is the subject plus action or production function. Character Identity uses only neutral view/pose work, not a current Scene's plot action. Scene states environment and usable space. Graphic starts with the information goal. Context absence is an explicit background choice, never null.

Use `product_evidence` only for inspected truth-preserving product work. It forces optics and true-color decisions, locks approved logo/layout/ports/proportions/wear, and blocks grade, negative-rule, or variation conflicts. Story Props remain compact and do not receive product photography detail without a trigger. Graphic does not receive photography filler.

For `cover_visual`, reuse the Key Frame template for current action, identity/scene/style reference responsibilities, and continuity locks; reuse Graphic rules only for clean title-space reservation and post-layout exact Chinese. Require platform-native composition, UI avoidance, thumbnail readability intent, and `generate_text_in_image=false`. Do not add another Prompt compiler or Adapter.

For a VOX Pilot image, require the inherited `pilot_design_route`. `hero_key_art` preserves the approved visual-impact intent and may allow a highly fused complete composition; never inject reconstructability as a hidden acceptance requirement. For `production_reconstructable`, automatically compile a route clause with this meaning: create one visually strong, coherent editorial poster while major typography groups, directional graphics, decorative ink/seal elements, and context groups remain visually separable and independently reconstructable. Preserve negative space, avoid large cross-element texture entanglement and continuous full-width scenery strips, and do not create a design that would require rectangular screenshot crops. The clause must not prescribe a fixed layer count, fixed layout, fixed palette, or project-specific visual constants.

The route clause augments the current image Prompt; it does not replace the type-specific template, Visual Baseline, critical-text ownership, factual locks, or v1.8 decomposition decision. Missing/unknown route for a declared VOX Pilot blocks Prompt compilation. A Production result that later proves visually strong but over-fused may be recommended for `hero_key_art` by the existing Review and retained through existing salvage/reuse; the compiler does not reclassify unseen media.

When any generated production asset requires a transparent PNG, compile the approved call for the existing ChatGPT Web conversation associated with the current Work/Codex task. Conversation availability, actual saved-file Alpha, the Visual Baseline, and the exact Cost Gate remain runtime evidence; do not fabricate them, silently open a new conversation, or switch image routes.

For a ready VOX Poster Shot, compile only assets allowed by its current `decomposition_decision`. `keep_whole` must not trigger component generation merely because extraction is possible. `partial_decomposition` requests only elements with an evidenced independent motion/occlusion/emphasis need. `full_element_assembly` requires an approved complete layer plan. `rebuild_locally` routes deterministic typography, maps, timelines, cards and simple graphics to Remotion/SVG/local graphics before considering generation. A small number of high-quality hero posters may remain whole while the rest of the video uses the VOX editorial system.

Derive `background_plate_strategy` from the approved motion exposure. Compile no plate when hidden areas will not be shown; for local exposure request only the bounded regions plus a justified safety margin. A full plate requires evidence that the camera/layers can reveal near-full hidden background. Do not ask image generation to invent hidden historical, cultural, product or identity facts.

Critical text remains `owner: remotion` even when realized as `verified_typography_svg` or `verified_typography_png`. Remotion owns placement, scale and timing. Verify exact glyphs/order/fact text, Alpha, delivery-size readability and rights. When Hero Typography character cannot be preserved by `remotion_native_text`, compile a verified SVG/PNG or local custom construction instead of an ordinary CSS-font fallback. Historical/cultural hero numerals default to locale-appropriate written forms; modern data graphics may retain Arabic numerals. Preserve source value, unit, scale, date meaning and fact semantics in every display conversion.

For the VOX-only `manual_crop_from_named_transparent_atlas` option, first retain the existing one-element-per-`asset_id` plan, `image_prompt_spec`, and `call_package`. Compatible small elements may be grouped into exactly one temporary `atlas_prompt_projection`: use `2x2` for one to four elements and `3x3` for five to nine. It is a copy-ready ChatGPT Web prompt plus an external filename list, not a Production Asset, Manifest field, state source, or readiness proof. Group only elements that share one evidenced destination-background and cut-paper-outline contrast basis. Record that destination background, and give every cell a project-specific `asset_constraints` sentence for any applicable era/clothing, identity, facing direction, pose, complete hands/feet, and complete props; these values come from the current Asset Requirement and never become global VOX constants.

Keep VOX identity references and per-Shot pose assets distinct. Every individual pose request and every atlas cell must inherit all applicable era/clothing, identity, facing direction and target, gesture, prop-contact, complete-silhouette, and destination-background requirements from the current Asset Requirement. Persist pose/facing, foot-or-base anchor, and hand/prop contact in the owning asset/Shot record; atlas prompt text alone is not a binding. Validate source silhouette completeness separately from a declared final close-up crop.

Each cell contains one complete subject inside its safe area on a genuinely transparent requested background, with wide gutters and no text, labels, arrows, grid lines, checkerboard, or complex scene. Do not bake a new cut-paper outline into the requested PNG by default: retain clean Alpha so Remotion can apply a background-aware, role-based, delivery-resolution-aware runtime outline. When an already approved source intrinsically includes an inseparable outline, preserve and record it instead of adding a second one. Paper-layer shadow remains separate. No global `10px/8px/6px` outline constants are compiled. Unused cells stay empty; never duplicate an element to fill a cell.

`call_package.generation_status` remains `blocked`; no generation, automatic crop, Alpha claim, or Remotion bind is implied. After the Web result is saved, verify the real Alpha channel, then use `scripts/split-transparent-atlas.ps1`, which resolves the approved Pillow runtime and invokes `split-transparent-atlas.py` for named row-major crop only. The tool must fail on an opaque source, empty mapped cell, non-empty unused cell, unsafe edge contact, or unapproved overwrite; it does not remove a solid background, invent or recolor an outline, call a provider, or make the atlas formal state. Route each independent output through existing intake, RGBA/Alpha, edge, and safe-area checks before binding it back to its original `asset_id`; validate the Remotion runtime outline and separate shadow later on the bound background at delivery size.

If a generated result is unsuitable for its original Shot, do not immediately discard or regenerate it. Under the existing asset/Production QA record, assess `later_beat`, `hero_poster`, `cover`, `title_card`, `detail_crop`, `background`, and `transition` in that order; select `reject` only after all prior dispositions are evidence-checked. A reuse target must preserve rights, identity, era, fact, approved composition, crop/text limits and intake requirements, and it does not authorize another provider call.

For every rendered sentence record its decision paths and acceptance effect. Fail closed for unresolved mandatory values, invalid statuses, missing inherited source, optics hard-trigger violations, true-color/grade conflicts, background conflicts, variation/lock conflicts, unverified product additions, or unmapped sentences. Local previews and Fixtures do not call a provider and do not prove visual quality.

For `whiteboard_animator` 1.3, accept only the derived `whiteboard_style_slice`, never the source Profile. The bounded local source compiler owns text, cards, arrows, icons, geometry, and deterministic simple flat elements at a 4x RGBA working canvas with premultiplied-alpha area downsample, explicit reading order, draw/z order, rights evidence, and SHA-256. Complex characters, illustrations, photoreal material, or non-deterministic imagery stop at a source brief / prompt package with generation unsubmitted; any external or paid call remains under the existing Visual Baseline and Cost Gate.
