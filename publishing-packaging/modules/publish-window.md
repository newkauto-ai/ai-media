# Evidence-based Publish Window

Use evidence in this order: current account audience activity, same-series history, comparable content history, audience routine/consumption context, then local platform heuristic. Output a window, evidence, sample period/size when available, assumptions, unknowns, audience timezone, UTC+08 display, and qualitative confidence.

With no account history, label both windows as experiments and confidence `low` or `unknown`. A concrete `operational_selection` is only a point chosen inside the window for manual operation; never call it a best time.
