# VOX Style Profile Changelog

This file preserves migration history for `vox_transcript_driven_handmade_collage`. The active runtime Profile contains only current executable guidance; this changelog is not inherited as runtime policy.

## v1.1-zh

- Established the stable formal ID and the transcript-driven editorial paper-collage grammar.
- Preserved image-first layered poster construction, limited palette, paper/print texture, controllable text, and narration-led information units.

## v1.2-zh

- Added the “camera explores one designed collage plus a living detail” recipe and semantic composition phases for longer clips.
- Historical `3–5%` and related motion ranges were recipe guidance only. Later versions removed any interpretation of them as global limits.

## v1.3-zh

- Made Remotion with imported final narration the recommended local recipe.
- Added Beat components, one Master Composition, readable holds, fixed procedural seeds, SFX anchors, depth parallax, paper-craft, marker, riso, ink and line-carry examples.

## v1.4-zh

- Integrated production evidence for flexible engineering/delivery resolution, responsive multi-card layout, transparent small-element atlas handling, final-narration timing and deterministic final-master technical checks.
- Kept atlases temporary: only individually checked RGBA PNGs become production assets.

## v1.5-zh

- Made the cut-paper outline background-aware: paper white/warm white are preferred, not mandatory on light backgrounds.
- Separated outline from paper shadow and kept era/clothing/identity/pose/completeness as project-level asset constraints.

## v1.6-zh

- Replaced restrictive defaults with shot-intent routing: static, dynamic and compound camera/layer motion became peer choices.
- Preserved one primary attention target at a time while allowing multi-stage motion, open motion vocabulary, variable layer counts, stronger camera moves and approved semantic end states.
- Kept living-poster and element-assembly as composable peer recipes and removed mandatory poster restoration/global end freeze.

## v1.7-zh

- Introduced `VOX Poster Shot` below ADP Beat and projected it into existing Scene/Shot/`local_assembly_plan` records.
- Required a readable `stable_poster_state` and Poster Readiness before motion.
- Derived Production Asset Set from approved Poster Shots instead of generating the whole Candidate Asset Plan.
- Added Remotion living-poster, Remotion precision-motion and generative hero-clip route decisions; generative hero clips require `why_not_remotion`.
- Made critical text Remotion-owned by default, added VOX Poster Contact Sheet and editorial-rhythm review, and kept all approvals, retries and actual-state ownership in existing systems.

## v1.8-zh

- Added minimum-sufficient Poster decomposition decisions: `keep_whole`, `partial_decomposition`, `full_element_assembly`, and `rebuild_locally`.
- Added Static Reconstruction Check as existing Poster Readiness / `previsualization_storyboard` findings, preserving composition, hierarchy, focal weight, negative space, palette, and typography character without requiring pixel-perfect equality.
- Added exposure-bounded background-plate recovery and generated-asset salvage order before reject: later beat, hero poster, cover, title card, detail crop, background, and transition.
- Kept critical text Remotion-owned while allowing native text plus verified typography SVG/PNG; protected Hero Typography from silent ordinary-CSS fallback.
- Moved new cut-paper outlines to background-aware, role-based, delivery-resolution-aware Remotion runtime styling by default, with shadow kept separate and no global pixel-width constants.
- Added historical/cultural numeral localization with source-fact semantic equivalence and retained Arabic numerals for modern data visualization.
- Formally allowed a VOX editorial majority with a small number of high-quality hero posters; full decomposition and torn-paper treatment are not mandatory for every Shot.
- Extended only existing `local_assembly_plan`, asset, Poster Readiness, Storyboard, Review Result, and Production QA owners; no Reconstruction Manifest/Gate, Typography Manifest, or Poster State Machine was added.

## v1.9-zh

- Added pre-generation `pilot_design_route`: `hero_key_art` for fused high-impact cover/climax/callback/Title Card/video-reference use, and `production_reconstructable` for VOX editorial body and Remotion precision shots.
- Added production-friendly design requirements for independently reconstructable typography, directional, decorative, and context groups inside one coherent poster, while preserving negative space and avoiding fixed layer/layout/palette/project constants.
- Added five Production Reconstructability findings under the existing Poster Readiness / `previsualization_storyboard` Review Result: typography split, context separation, decorative independence, rectangle risk, and motion sequence. Hero key art marks these not applicable.
- Made visible horizontal/vertical crop lines, background halos, full-width context strips, title-plus-background rectangles, and adjacent-element fragments `must_fix`; obvious rectangular screenshot crops are not an asset fallback.
- Allowed visually strong but over-fused Production Pilots to be recommended as `hero_key_art` and retained through the existing v1.8 salvage/reuse path instead of forced decomposition.
- Added the Production Pilot Prompt clause for a coherent poster plus independently reconstructable visual groups. Preserved all v1.8 decomposition, Static Reconstruction, Hero Typography, numeral localization, generative route, ownership, Gate, and state boundaries.

## v1.10-zh

- Added optional `style_profile.audiovisual_modules.historical_vox` v1.0 under the same stable VOX profile ID; no separate profile, registry ID, Gate, Manifest, state machine, retry owner, or planner was introduced.
- Added `historical_visual_mode` with `hero_cinematic`, `editorial_explainer`, and `atmospheric_historical`; non-historical Shots omit it or use `null` and retain v1.9 behavior.
- Kept Historical mode, Pilot design route, decomposition decision, and motion route as four orthogonal decisions.
- Added the reusable historical grammar of subject + evidence/context + editorial explanation, structural palette roles, material/period coherence, subject-grade historical people, explanatory maps/routes/timelines, existing Remotion-owned critical text, and inherited numeral localization.
- Routed era, identity, costume, architecture, terrain, exact palette, project typography, and recurring symbols to the Project Visual Bible instead of hard-coding project-specific historical constants into Style Core.
- Added mobile-readability and anti-scrapbook findings to the existing Poster Readiness / `previsualization_storyboard` Review Result, plus six structural fixtures covering valid mode combinations, route orthogonality, must-fix clutter, and invalid project-specific leakage.
