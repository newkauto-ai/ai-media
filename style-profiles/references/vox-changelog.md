# VOX Style Profile Changelog

This file preserves migration history for `vox_transcript_driven_handmade_collage`. The active runtime Profile contains only current executable guidance; this changelog is not inherited as runtime policy.

## v1.1-zh

- Established the stable formal ID and the transcript-driven editorial paper-collage grammar.
- Preserved image-first layered poster construction, limited palette, paper/print texture, controllable text, and narration-led information units.

## v1.2-zh

- Added the “camera explores one designed collage plus a living detail” recipe and semantic composition phases for longer clips.
- Historical `3–5%` and related motion ranges were recipe guidance only. Later versions removed any interpretation of them as global limits.

## v1.3-zh

- Made Remotion with imported final narration the recommended local recipe.
- Added Beat components, one Master Composition, readable holds, fixed procedural seeds, SFX anchors, depth parallax, paper-craft, marker, riso, ink and line-carry examples.

## v1.4-zh

- Integrated production evidence for flexible engineering/delivery resolution, responsive multi-card layout, transparent small-element atlas handling, final-narration timing and deterministic final-master technical checks.
- Kept atlases temporary: only individually checked RGBA PNGs become production assets.

## v1.5-zh

- Made the cut-paper outline background-aware: paper white/warm white are preferred, not mandatory on light backgrounds.
- Separated outline from paper shadow and kept era/clothing/identity/pose/completeness as project-level asset constraints.

## v1.6-zh

- Replaced restrictive defaults with shot-intent routing: static, dynamic and compound camera/layer motion became peer choices.
- Preserved one primary attention target at a time while allowing multi-stage motion, open motion vocabulary, variable layer counts, stronger camera moves and approved semantic end states.
- Kept living-poster and element-assembly as composable peer recipes and removed mandatory poster restoration/global end freeze.

## v1.7-zh

- Introduced `VOX Poster Shot` below ADP Beat and projected it into existing Scene/Shot/`local_assembly_plan` records.
- Required a readable `stable_poster_state` and Poster Readiness before motion.
- Derived Production Asset Set from approved Poster Shots instead of generating the whole Candidate Asset Plan.
- Added Remotion living-poster, Remotion precision-motion and generative hero-clip route decisions; generative hero clips require `why_not_remotion`.
- Made critical text Remotion-owned by default, added VOX Poster Contact Sheet and editorial-rhythm review, and kept all approvals, retries and actual-state ownership in existing systems.
