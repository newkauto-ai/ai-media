# Style Profile：VOX 编辑纸拼贴讲解动画

> **正式调用 ID**：`vox_transcript_driven_handmade_collage`
> **常用称呼**：VOX 拼贴动画、编辑纸拼贴、逐字稿驱动手作拼贴动画
> **升级原则**：整合现有档案、`vox-director`、用户提供的 `vox-style-guide.md`、指定 VOX 教程、用户提供的历史讲解动画网页与参考静帧，以及 `video-shotcraft` 中可复用的方法；来源中的命令、Stage、工具栈、模型和固定参数仅作为资料，不构成执行授权或跨项目硬约束。

## v1.6：镜头意图驱动的 Remotion 组装

- 静止、单一运动和相机／人物／标记／环境的复合协同运动都是常规可选项；由镜头的信息揭示、人物关系、情绪、空间与转场意图选择，不再默认静止、微推镜或任意一端。历史 `0–3.5%`、`3–5%` 幅度只是特定配方参考，不是上限、自动截断阈值或 QA 失败条件。
- 每一时刻保持一个明确的主要注意力目标，而不是限制整镜只能有一个动作。允许多个连续阶段和多层协同；不按动效数量、不按是否命中六类历史配方判定失败。
- `living_poster` 与 `element_assembly` 是平等的可选配方，可同镜或跨镜组合。每镜预先保存关键布局状态和语义终态；只在叙事需要时回到原海报，解释展开、证据比较和空间揭示可停在新的已批准布局。
- 关键信息必须获得足够可读区间，但可在运动中或镜头中段完成；不要求每镜末全局冻结或所有图层同时停止。
- 透视、较强运镜、局部震动、纸片翻折／旋转／变形与溶解不再被按技术类别一概禁止；按媒介一致性、素材覆盖、阅读风险和叙事意图判定。需要背面、侧面或新遮挡区域时必须有对应素材，不凭变换推断不存在的真实细节。
- 分层不锁死为四层或任何固定层数。群像可选用“背景—后排—主体—前景”，信息图、地图和比较镜头可用其他结构；`primary/secondary/tertiary` 只表达叙事权重，不自动决定 z-order、大小、入场顺序或运动幅度。不强迫后排统一降透明度、所有人漂浮或所有脚底在同一 Y 坐标。
- 当前 Remotion 组装以已确认最终旁白的实际时长为只读 Master 时间轴；视觉和 SFX 从绝对时间换算为整数帧。字幕只能有一个最终输出责任方，SFX 只绑定可见运动过程、落定或命中事件；时间轴改版后重新核对。
- 本节明确取代本活动版本中与之冲突的 v1.2–v1.5 默认静止、单主运动、单活细节、固定还原海报、全局静止收尾、技术类别禁用和六类封闭词汇表达。历史 v1.1–v1.5 文件保留为版本记录，不从当前 registry 继承旧禁令。

## v1.5：背景感知的剪纸轮廓层次

- 剪纸轮廓的目标是让主体在最终合成背景上形成清楚、连续、可读的纸片层次，而不是固定使用白色。默认优先纸白或暖白；若最终背景同样偏白、偏亮或低对比，应改用与背景在明度、色相或冷暖上明显分离、同时仍属于当前纸张色板的轮廓色。
- 轮廓沿完整 Alpha 外形包住人物、发冠、衣袖、手脚、道具和其他附属物；不能出现矩形底板、局部断边、吞掉五官与服饰细节的粗边，或缩小到交付尺寸后消失的细边。
- 纸质轮廓与纸层投影是两个独立层次。投影保持低饱和、方向一致并服务贴纸离地感；不能用重阴影代替轮廓，也不能叠出双重描边或浑浊光晕。
- 同一镜头和同一连续视觉系统中的轮廓语言保持一致；颜色与粗细可随目标背景调整，但变化必须有背景对比依据。最终是否清楚以绑定交付规格后的真实静帧和人工观看为准，不以提示词或源图尺寸代替。
- 题材服饰、年代、人物身份、朝向、动作、完整手脚与道具属于项目级 Asset Requirement。它们可进入图集的逐格约束，但不得硬编码为 VOX 通用 Style Core。

## v1.4：真实 Remotion 生产经验边界（由 v1.6 意图语义修订）

- 镜头可静止、可运动、也可分阶段协同运动，按叙事意图选择。`0–3.5%` 是单一旧项目的可调整参考，不是默认、必用、上限或跨项目硬阈值。
- 同时保持一个主要注意力目标；相机、人物、标记和环境可为同一信息任务协同。关键信息获得可读区间，但无需所有图层一起静止。光环、圆环、箭头和强调线必须绑定主体或观点，并有进入、保持、退出生命周期；主体或观点退出后不得残留为无语义装饰。
- Remotion 本地工程规划默认 `720×1280`，但这不等于交付规格。当前 Adapter 或用户可选择 `480P`、`720P` 或其他明确的交付规格；检查只比较当前已绑定规格。
- 文本卡背景可按内容收口并受最大宽度与安全区限制。同画面多卡片先选择左边缘、右边缘、中心线或文字基线之一作为组对齐轴；垂直间距由可用空间、主体避让、卡片数量和阅读层级决定，不固定像素值或唯一算法。若未锁定的重复小字仍遮挡主体，可建议省略；已锁定文字交由导演或人工决定。
- 需要透明 PNG 的生成素材默认使用当前 Work/Codex 任务对应的既有 ChatGPT Web 同一对话，并继续经过独立 Visual Baseline 与 Cost Gate；入口不可复用时不得自动新建对话或切换生图路线。兼容的小元素使用能容纳它们的最小 `2×2` 或 `3×3` 透明图集：每格一个完整主体、宽 gutter、安全留白、无图内标签，空格保持为空且不重复素材。下载后先核验真实 Alpha，再本地裁切；Remotion 只接收分别通过既有 media intake、RGBA/Alpha、边缘和安全区检查的独立 PNG，图集本身不成为正式素材或透明通道证明。
- 已批准的最终旁白是唯一连续、只读的 Master 时间轴。所有 Beat 以原音频绝对时间码布局；自然停顿默认保留。删除停顿、变速或重切都意味着新音频版本，必须重新确认。最终技术探针只能核对已绑定的文件校验和、音频流时长、规格与可解码性，不能冒充 Final Cut 语义验收。

## 适用范围

- 适合把讲解、历史、商业、产品或观点型内容转成旁白驱动的编辑纸拼贴短片。
- 每个 Beat 只承担一个可复述的信息点、转折或证据；用一个主视觉隐喻和少量有功能的纸片元素表达。
- 事实、论点、CTA 和叙事顺序继续由 Topic / Script owner 决定；本档案只规定如何看见、听见和组织这些内容。
- 纯装饰拼贴、连续写实表演、需要真实空间物理连续性的场景不是默认适用项，应先做兼容性判断。

## 讲解结构与口播接口

- 事实、观点和最终叙事顺序仍由 Topic / Script owner 决定；本 Profile 只提供适合 VOX 讲解片的默认节奏接口，不替代上游脚本审批。
- 可采用“具体反常事实或问题冷开场 → 拉远补充语境 → 沿单一主线逐层解释 → 暴露代价、限制或反讽 → 回扣开场并重构意义”的解释弧。若主题不需要其中某段，可以合并或省略，不为套模板制造虚假转折。
- 每个 Beat 优先使用具体数字、专名、可比较尺度和可观察结果，少用只有形容词的抽象概括；历史讲述是否使用现在时由文案语境决定。
- 口播句子按听觉而非页面阅读优化：长短句交替，数字写成实际读法，生成前朗读或用 TTS 试读；任何拗口、歧义或无法自然停顿的句子先回上游修订。
- 时长预算应由实际旁白语速、停顿和目标片长反推，不把固定字数、固定 Beat 数或单一语速写成风格硬规则。

## 风格核心：先验证关键布局，再按镜头意图组织运动

- 每个 Beat 先验证信息完整、构图成立的关键布局状态；可是完整海报，也可是解释展开、比较或空间揭示中的一个稳定状态。动效不能挽救层次薄弱、信息混乱或只是“贴纸堆叠”的画面。
- 海报必须能辨认前景、中景、背景和独立纸片：主体、道具、标题条、报纸碎片或几何装饰各有清楚边缘、材质差异和纸层投影；需要强化剪纸感时，使用与最终背景清楚分离的背景感知纸质轮廓。
- 跨 Beat 固定纸张触感、裁切语言、半调密度、标题层级和总体时代语汇；主题色和局部素材可随叙事推进变化。
- 默认保持正面或近似扫描件的二维观看关系；纸层可以产生轻微景深和视差，但不能漂成光滑三维渲染。

## 教程补强：从旁白时间线到可复现镜头

指定教程演示的核心价值不是 `Claude Code + Remotion` 的工具组合，而是把旁白、资产、构图、动效、布局记录和最终组装连成一个可回读闭环。

### 1. 旁白先成为镜头时间线

- 在制作资产前，先把已批准旁白拆成语义 Beat；每个 Beat 至少明确旁白范围、核心信息、主视觉、背景、中景、前景、可控文字和素材需求。
- Beat 的起止优先落在完整语义句、转折或论证步骤上，不按固定秒数平均切段。
- 图像提示词只是 Beat 资产说明的一部分，不能替代信息目标、构图职责和文字校对。
- 最终组装以导入后的最终旁白音频为时间依据；旁白仍会改写时只能做预演，不冻结镜头时长。

### 2. 锁定全片视觉系统，再允许局部变化

- 全片先锁定背景系统、字体层级、强调色、半调处理和纸张质感，再逐 Beat 更换人物、建筑、道具与证据素材。
- 教程用“同一静态背景贯穿全部场景”获得连续感；本 Profile 把它保留为高效配方而非硬规则。主题需要换景时，仍应共享网格、材质、色板或背景母版中的至少一个连续性锚点。
- 黑白半调人物或建筑剪影适合承担摄影证据感；强调色、标记线和标题条负责引导阅读，不让所有层同时高饱和。

### 3. 分层必须有职责，但不锁死层数

- **背景层**：提供连续的纸面、网格、地图、档案或环境母版，默认最稳定、运动最少。
- **中景层**：承载人物关系、论证对象或主要事件，通常是 Beat 的信息主体。
- **前景层**：承载建筑、证据物、数字、标题、标记线或遮挡转场，负责强调和建立阅读路径。
- 背景—中景—前景是可选的解说镜头配方，不是固定三层或四层模板。某层没有信息职责时可以为空；信息图、地图、比较镜头和群像可用不同结构，但主体、证据和文字不能争夺同一视觉焦点。

### 4. 用“动效意图”编排，而不是堆动画参数

- 每个 Beat 先写清 `谁先出现 -> 谁随后响应 -> 哪个标记负责强调 -> 最终停在哪里`，再交给当前生产引擎实现。
- 一种可选基础节奏是：主对象先建立，相关人物或证据错峰进入，强调色标记随信息揭示，最后进入可读的已批准布局。其他先后顺序由镜头意图决定，不强制主体先入场或最大。
- 弹入、轻微过冲、错峰和偏移标记线可以制造编辑节奏，但不能让所有元素同时弹跳，也不能在信息尚未读清前离场。
- 运动描述应包含对象、方向、先后、强调目的和终态；只写“让画面更有动感”不可执行，也不可验收。

### 5. 保存布局状态，并区分预览与成片证据

- 人工调好的缩放、X/Y 位置、层级、裁切和关键时间点必须保存为可回读布局状态；不能依赖未保存的预览界面位置。
- 单场景调试通过后，再按旁白边界组装总时间线；不在同一轮里同时改布局、旁白边界和音效锚点。
- 预览卡顿、声音断续或低清代理不直接等于成片失败；质量结论基于最终导出文件的画面、声音和同步检查。

## LOOK 轴

每个项目从以下轴各作一个明确选择，并在同一成片内保持一致；具体取值由当前主题和已批准参考决定，不建立第二套主题库。

- **媒介**：手剪或撕纸、摄影剪贴、报纸印刷、丝网/孔版印刷、复印机颗粒、木刻或平涂插画中的一种主语言。
- **时代与设计语汇**：例如现代编辑、国际主义网格、构成主义、朋克小志、装饰艺术或在地文化印刷传统；不得仅为“好看”混搭互相冲突的年代语汇。
- **构图**：明确海报层级、焦点、留白和阅读方向；一个主角或主对象，卫星元素只用于强化主题、建立语境或平衡版面。
- **色彩**：优先有限色板、单一平涂底色和一个贯穿全片的强调色。允许经批准的色彩沿叙事弧有控制地推进，但不得让强调色在相邻 Beat 无动机漂移。
- **字体与文字**：标题作为设计资产处理，短、粗、层级清楚；逐字核对拼写。关键事实、品牌名和长字幕优先保留为后期可控文字层，而非交给视频模型重绘。
- **纸面质感**：可见纤维、毛边、折痕、轻微套印错位、胶带、半调网点、背景感知纸质轮廓和真实纸层阴影；质感服务层次，不覆盖人脸、产品标签或关键信息。

## Beat 与镜头组织

- 一个 Beat 对应一个核心信息单元和一张主海报；需要更强节奏时，同一 Beat 可派生“建立画面 + 细节切入”，但两镜必须共享同一信息目标和视觉身份。
- 开头直接展示承诺、反差、问题或关键事实，不用空泛的品牌片头消耗注意力。
- 相邻 Beat 应有可感知的构图、焦点、色彩或纸片状态变化；变化频率由目标时长和平台决定，不写死秒数。
- 运镜在相邻镜头间避免机械重复；静止或近静止应留给结论、数字、引语或兑现点，让节奏下降本身成为强调。
- 视觉双关必须忠实于原稿；不能为了制造奇观改变事实、因果或人物立场。
- 文化适配只替换与主题有关的素材语汇，例如在地印刷、档案照片、纹样、印章或字体气质；背景感知的高分离度纸质轮廓、真实纸层、半调、有限色板和编辑层级仍保持同一套拼贴语法。
- 每个 Beat 应有一个最小资产包：旁白范围、主海报/构图参考、分层素材职责、关键文字、动效意图和稳定终态。可以按场景分文件夹管理，但目录形式由当前项目决定。

## 可平等选择和组合的动效路线

### A. 会动的海报

- 常用句法是“镜头探索一张已设计好的拼贴”。可使用静止、快慢推拉、横移／跟随、视差滑轨或多阶段重构图；运动必须保留纸层媒介和当前信息焦点。
- `3–5%` 全镜头缩放只是历史配方参考，不是默认起点、上限或失败阈值。背景、中景和前景的运动关系按空间与阅读意图设计，不自动假设背景必须慢于前景。
- 环境细节可有多个连续阶段，但每一时刻都不应与主要注意力目标争抢。人物脸部、口型或身份特征的动画仍需明确意图、素材覆盖和适用授权。
- 需要入场时，一个或多个元素可按阅读路径进入、强调、退出或重组。三维 dolly、环绕、透视旋转、局部震动、镜内形变或溶解只在媒介一致、素材覆盖充足且不破坏阅读时使用，不以技术类别本身判定。
- 元素运动可以丰富，但必须各自服务本 Beat；避免所有碎片同时随机飞行。
- 文字、Logo、人物面部、产品外形和标签保持稳定；运动远离关键文字区，结束时落到清楚、可读的状态。
- 避免纸片弯曲、融化、变形、突然改景、镜内跳切和无动机透视旋转。

### B. 拆件组装

- 在碎片进入、证据对照、关系建立或空间重组本身承担信息任务时使用；不因其实现成本而自动降级为例外路线。
- 每个元素的终点必须落在预先批准的语义终态；只在需要还原原海报时回到原位置，否则可进入新的已批准布局。
- 入场可用飞入、拍入、落下、弹入和轻微过冲，但先后顺序必须建立阅读路径；最终停稳并兑现完整海报。
- 拆件、清理遮挡、补背景和逐件编排属于生产成本；应由当前项目在生产层选择实现方式，不能把某个本地引擎当作风格硬依赖。

## Video-shotcraft 补强：VOX 可用的动效配方

`video-shotcraft` 主要为产品宣传片设计，不能把其 UI、品牌片节奏或整套模板直接套进旁白讲解。这里只吸收与编辑纸拼贴同媒介、同信息目标的运动语法。

### 通用动效纪律

- **一个时刻只有一个主要注意力目标**：组装、视差、描线、套印命中、介质转场、人物动作和相机运动可协同或分阶段继承焦点，不用整镜动效数量判定。
- **关键信息必须有可读区间**：标题、数字、证据或关键布局可在运动中或镜头中段被读清，不要求每镜末全画面真正静止。具体帧数由旁白、帧率、相对运动和可读性决定。
- **速度感来自加速度和错峰**：避免匀速直线飞入。批量纸片应有物理隐喻、非均匀错峰和明确收束，最后回到可读终态。
- **相机只放大叙事，不制造噪声**：静止、元素层运动、轻视差、大幅 dolly、整画面 scale、震屏和闪帧都按镜头意图、阅读风险和素材覆盖选择；不默认任何一类，也不以幅度或类别单独判定。
- **可复现优先**：噪声、颗粒、墨渗和随机散布使用固定种子；相同输入与同一帧必须得到相同画面。

### 开放的 VOX 动效示例

1. **三层视差滑轨**（源卡 `depth-layer-moves`）：背景慢、中景承担阅读、前景较快掠过；主阅读层保持清晰，前后景可轻微降饱和或虚化。它让平面海报有厚度，但不把纸层变成写实 3D。
2. **胶带拍定 / 立体书起身**（源卡 `paper-craft-moves`）：胶带落下应与纸片停止晃动、阴影收紧和轻微下沉同拍；立体书动作只用于构图建立，信息必须在回到可读角度后呈现。
3. **马克笔关键词下划线**（源卡 `marker-underline-title`）：标题先落定，短暂留白后快速描线；线要贴字底、跟随字势、保留粗细与毛糙变化，不能像加载条或 CSS 边框。
4. **套印错位命中**（源卡 `riso-print-hits`）：用纸墨浅/深双色版的短暂错位替代数字 RGB 故障；只用于论点、数字或标题的少数高能命中，套准后立即稳定并留白。连续节拍泵不是旁白片默认项。
5. **墨渗揭示**（源卡 `print-texture-transitions`）：新场景像墨在纸上扩散显影；遮罩只作用边界，正文、人脸和 Logo 保持清晰，完成后摘除动态遮罩以获得真静止。
6. **线条接力转场**（源卡 `line-carry-transition`）：从旧景已有的下划线、地图路径或图表轴自然延伸到新景，线的身份承担叙事连接；全片作为一次招牌转场使用，不能凭空起线或反复炫技。

这六个卡名只是可复用示例，不是封闭白名单、每片配额或 QA 计数器。允许其他符合纸片媒介、信息任务、素材覆盖和确定性渲染要求的运动，也允许一个都不用。它们不把 `video-shotcraft` 的 demo、组件、依赖或模板变成本 Profile 的运行依赖。首次用于真实 VOX 素材时，必须以实际静帧和成片回验参数。

## 人物、产品与真实素材锁定

- 使用真人照片或产品图时，把主体视为摄影贴纸锚点；保留身份、表情、产品轮廓、材质反光、Logo 和标签文字。
- 身份基准素材与镜头姿势素材分工：前者锁定人物身份与服饰语汇，后者必须逐个继承适用的年代／服饰、身份、朝向、手势、道具接触、完整轮廓和目标背景要求。人物姿势、面向对象、脚底／底座锚点与手道具接触都是镜头布局的可回读输入，不能只在图集提示词中补写。
- 全身源素材完整性与成片的有意特写裁切分别判定：未声明的断手、断脚或道具断裂为素材失败；有意裁切必须有镜头目的并保留当前要读的脸、手、道具或文字。
- 插画化、半调或纸纹只作用于主体之外的纸片世界，除非用户明确批准对主体本身的重绘。
- 人物动作优先由纸偶身体、手势或周围元素表达，不通过重绘脸部制造新表情。
- 视频阶段仍需抽帧复核人脸、Logo 和每个关键字；“静帧正确”不等于“动起来仍正确”。

## 声音方向

- 讲解型成片由单一、连续的旁白承担信息主线；画面、标题和音效不重复塞入同一层信息。
- 音乐以器乐节奏和编辑感为主，在旁白下让位；纸张拍入、撕裂、翻页和印章声只同步关键可见动作。
- 若项目本身是无旁白的视觉短片，可省略旁白，但必须由画面内状态变化独立完成信息传递。
- 旁白由外部工具生成并导入时，把最终音频当作只读主时间轴；画面锁定后再钉纸张、描线、拍定、转场和命中 SFX，镜头时长或顺序变化后必须重对全部 SFX 锚点。
- SFX 按可见动作与材质选词：纸片/翻页/撕裂优先纸声，运镜用克制 whoosh，落定用轻 impact，描线用笔擦；每一条都应能指回一个可见事件，不能凭感觉铺满。
- 若另配 BGM，先保证旁白清楚，再按内容节奏决定是否卡拍；只有已选定强节奏音乐时才启用节拍分析，默认只让元素层命中拍点，不做逐拍整画面泵动。

## 字幕方向

- 字幕是现有 caption pipeline 的输出层，不交给图像或视频模型重绘。默认使用高对比粗体无衬线字、稳定描边或硬阴影，并与项目强调色建立有限联动。
- 以语义短语和从句边界分块，避免在词组中间断开；默认不超过两行。每条可选择一个关键词使用强调色，但不能让逐词高亮抢走主画面焦点。
- 字号、行宽、边距、每行字符数和烧录方式由平台、画幅、语言与安全区决定，不写成跨项目固定像素规则。

## 失败判据

- 静帧像扁平 PPT、贴纸合集或光滑 CGI，而非具有纸层、印刷和编辑层级的完整海报。
- 每个 Beat 同构、同运镜、同节奏，只有文案和底色变化。
- 标题抖动、拼写漂移、人物身份或产品标签被重绘。
- 相机、人物、标记或环境运动没有共同的叙事意图，在同一时刻争抢注意力，遮挡当前关键信息或使关键布局不可读。
- 三维空间穿梭、环绕、透视漂移、纸片形变或溶解需要的背面／侧面／遮挡后区域素材不存在，或者无授权地改变人物脸部、口型、身份、关键文字与事实。
- 同时激活的细节、粒子、纹理或震动导致主信息失焦；或使用形变、溶解、震动掩盖布局设计不足。
- 组装或重构图没有进入预先批准的语义终态，或元素时序不能建立信息阅读路径。
- 将有意特写裁切误判为源素材不完整，或反过来放过未声明的保护对象裁断；Remotion 与外部后期重复烧录字幕；SFX 没有可见事件锚点或在旁白改版后没有重对时。
- 拼贴元素有装饰性但没有叙事功能，视觉隐喻改变了原稿事实或因果。
- 同一镜头并列使用多种招牌动效，或关键信息刚落定就切走，没有可读静止帧。
- 使用匀速飞入、随机抖动、逐拍整画面缩放或无语义转场，把旁白片做成动效样片。
- 纸墨项目使用荧光 RGB 故障、光滑数字粒子或游戏化音色，破坏媒介一致性。
- 随机噪声没有固定种子，导致同一帧不可复现；只看 Studio 预览而未检查真实导出。
- 把轮廓色永久锁死为白色，导致主体在白色或浅色背景上消失；或轮廓与背景没有可见分离度。
- 轮廓出现断边、矩形底板、截断手脚或道具、双重描边、背景色污染、Alpha 毛边，或粗边吞掉人物与服饰细节。
- 用重阴影冒充剪纸轮廓，或轮廓与投影方向、色彩和厚度在同一镜头内无依据漂移。

## 生产层边界

- 模型、供应商、API key、分辨率、画幅、固定时长、帧率、费用、自动重试、字幕烧录、混音命令和导出工具都由当前 Adapter / Prompt Compiler / Gate 决定。
- 不引入 `beats.json`、Atlas Cloud、ffmpeg、本地拆件引擎或新的审批 Gate 作为本档案的依赖。
- 现有 `selected_style_profiles`、Controller、Audiovisual Director、Video Production、Review 和 retry 机制保持唯一 owner。

### 推荐本地配方：Remotion + 外部旁白导入

- 此 Profile 的默认本地实现优先采用 **Remotion**；不把 HyperFrames 作为这条 VOX 路线的默认引擎。若项目另有明确选择，Style Core 仍可迁移。
- 旁白由外部音频工具生成并导入，Remotion 不接管旁白生成；导入后的最终音频文件及其真实时长是主时间轴依据。
- 每个 Beat 建成可独立预览的场景组件，再由 Master Composition 按旁白语义边界排序；共用背景、字体、色板、半调与标记组件集中复用，避免每个场景复制一套视觉规则。
- 需要在 Remotion Studio 手动微调的主要纸片，使用清楚的元素名称和可保存回代码的交互结构；只暴露对构图有用的缩放、位移、旋转和关键帧，不把每个碎片都变成控制项。
- 场景调试、总时间线组装和最终渲染分开核验：场景看构图与终态，总时间线看旁白边界，最终导出看音画同步、文字、人脸、Logo 和声音。
