# 风格档案：低调光中世纪政治史诗

## 解析结论

这是一份以**地域化调色、单一可信光源、做旧实体材质、权力构图和冷酷政治空间**为核心的中世纪史诗风格档案。源文档直接依赖具体作品名称、角色和地名；规范化后，作品名只用于来源追踪，生产目标改为原创中世纪政治奇幻，不复刻人物、家族标志、王座、地理名称或剧情。

## 适配范围

- 强适配：王权、阴谋、战争、宗族、北境生存、宫廷博弈和中世纪政治奇幻。
- 中等适配：历史战争、黑暗奇幻、古堡悬疑，但需要移除不必要的魔幻或宫廷元素。
- 弱适配：明亮童话、轻喜剧、现代都市和依赖干净高科技材质的题材。

## 脚本前置约束

- 视觉风格不能自动添加特定家族、王位斗争、龙、冰墙或原作角色。
- 政治张力通过身份等级、空间位置、视线、服饰和仪式表达，不靠旁白解释所有权力关系。
- 原作角色、经典台词和专属地名必须替换为原创人物、地点和制度。

## 视听风格规则

### 地域化色彩

- 寒冷北方：低饱和、较高对比、青蓝阴影、冰灰和冷色自然光，强调绝望与距离。
- 温暖南方或贸易地区：琥珀与金色高光、尘埃空气、较暖皮肤反光，可降低局部对比。
- 地域色彩是场景属性，不能把同一调色套在所有地点。

### 光源与材质

- 室内依赖烛光、火把、壁炉或窗外自然散射光；大面积暗部和背光轮廓建立空间深度。
- 禁止无来源的大平光、均匀棚拍感和干净数码表面。
- 皮肤保留汗、灰尘、风化和真实粗糙；服装使用重皮革、粗毛皮、金属扣件、手工针脚与有因果的磨损。
- 做旧应分布在接触、摩擦和天气暴露位置，不是全身均匀涂脏。

### 构图与摄影

- 框中框表现监视、压迫和被困；低角度表现权威；绝对对称表现制度秩序；浅景深特写表现孤立；隐蔽长焦表现窥视和谍报感。
- 文戏重视微表情、视线和道具；动作戏遵守空间轴线并以清楚的动作时序推进。
- 分镜展示板的格数、中心蓝图和摇臂路线属于生产设计工具，不是成片的永久审美要求。

### 声音与音乐

- 配乐以低沉、克制、庄严的中世纪或暗色器乐为方向，避免直接引用具体作品主题曲。
- 火、风、盔甲、皮革、石室混响和远处军队声构成空间真实感。
- 对白与旁白优先于配乐；政治文戏默认直接硬切，动作连续段可使用极短过渡。

## 连续性规则

- 每个地区锁定调色、光源类型、建筑材质和天气。
- 角色服装层级、泥灰分布、盔甲损伤、武器位置和身份标志跨镜保持一致。
- 相邻动作镜头维护轴线、人物位置和受力结果；文戏维护视线和空间权力关系。
