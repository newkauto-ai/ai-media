# 风格档案：八九十年代港式民俗恐怖喜剧

## 解析结论

这是一份“**民俗仪式可信度 + 阴森悬念 + 市井肢体喜剧 + 利落功夫动作**”并行的混合型风格档案。真正可复用的风格不是某位演员的肖像或某部影片的具体角色，而是冷暖光对撞、复古胶片、道观与义庄空间、实体法器、动作与声效卡点，以及“恐怖压迫—滑稽泄压—斗法爆发”的节奏结构。

源标题和人物原型只用于来源识别。正式生产应创建原创道士、徒弟、僵尸或鬼怪，不把演员面容、标志造型、角色名或经典台词当作必须复刻的规则。

## 适配范围

- 强适配：民俗怪谈、道观或义庄、师徒闯祸、追逐与斗法、惊吓和喜剧交替的短片。
- 中等适配：纯恐怖、纯功夫或民国奇谈，但需要主动调节喜剧占比。
- 弱适配：写实犯罪、现代都市科技恐怖、没有民俗物件与仪式逻辑的泛鬼片。

## 脚本前置约束

- **直接提取**：常见结构为平静日常 → 异兆 → 调查或师父登场 → 开坛斗法 → 尘埃落定。
- **结构归纳**：该结构是可选叙事骨架。若用户已有冻结剧情，只提取其节奏功能，不添加未授权的鬼怪、仪式或笑料。
- 喜剧负责释放压迫，不应把真正危险完全消解；斗法需要明确目标、法器、动作因果和结果。
- 民俗术语、仪式步骤和历史背景若被当成事实使用，必须另有可靠来源；本风格档案只定义呈现方式。

## 视听风格规则

### 视觉身份

- 八九十年代港产类型片胶片感：柔和暗调、可见颗粒、轻微朦胧、暖黄烛光与冷青或偏绿月光对照。
- 空间以老道观、法坛、义庄、深夜林地等为典型，但须根据故事实际选择，不自动套用全部场景。
- 法术避免抽象无来源白光，强调朱砂颗粒、灰烬、尘埃光路、热浪扭曲、符纸燃烧和实体碰撞。

### 角色与表演

- 原创师父：姿态挺拔、目光专注、动作干净；外形不以特定演员肖像为锁。
- 徒弟型角色通过重心失衡、抱头逃窜、相互拖累、误用法器、翻白眼和憋气等具体身体动作制造喜剧。
- 僵尸或鬼怪的威胁感来自僵直运动、突发冻结、光影变化与声音，不依赖血腥伤口。
- 表情描述落到眼球方向、嘴型、面部肌肉和身体受力，避免只写“滑稽”“凶狠”。

### 场景与道具

- 法坛重视祭器、香炉、烛台、符纸和木剑等陈设关系；义庄重视棺木排列、梁柱、纸灯和瓦缝月光；林地重视古树、乱石、雾和幽深路径。
- 八卦镜、墨斗、朱砂砚、法笔、符纸和木剑应有可读材质、磨损和握持方式。
- 道具的出现、位置、交接和消失必须跨镜连续，避免临时凭空出现。

### 摄影、动作与剪辑

- 文戏与悬念保留呼吸；追逐、武打和斗法以短促硬切推进。
- 法术或撞击爆点可使用极短慢放或反应定格，但只在关键节点使用。
- 手势、剑指和结印必须写成具体指节关系和轨迹；功夫动作强调起势、重心、反作用力和落地缓冲。
- 同一场景保持空间轴线、光源与陈设连续；四宫格参考只是生产资产，不应直接泄露为多格视频。

### 声音与音乐

- 核心声音包括铃、木剑破风、糯米爆裂、符纸燃烧、墨线弹击、木质与金属碰撞、风声和棺木摩擦。
- 音乐可融合唢呐、二胡、锣鼓和复古电子底色，但配器比例不是永久硬阈值。
- 喜剧撞击、法术爆发和动作接触点需要声画同步；对白优先于音乐与环境声。
