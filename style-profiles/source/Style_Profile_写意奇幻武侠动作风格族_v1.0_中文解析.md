# Style Profile：写意奇幻武侠动作风格族

> **版本**：v1.0-zh  
> **源文档**：`徐克电影美学：新派武侠、聊斋玄幻与近代功夫短片.md`  
> **内部风格 ID**：`expressive_fantasy_wuxia_action_family`  
> **解析原则**：创作者姓名与具体作品只保留在来源说明，不作为运行时提示词依赖；把模仿请求拆成写意空间、冷暖色彩、动作能量、奇幻物理、声音和剪辑规则。

---

## 0. 解析结论

该文档应归类为 **三分支武侠动作风格族 + 动作声音剪辑系统 + 生产手册**。共同核心是：写意浪漫、仙邪并存、强烈冷暖对照、空气介质、极静与极动、超常动作、夸张但有方向的能量反馈、兵刃与拳脚声效，以及动作点硬切。

三个分支是：新派古典武侠、聊斋玄幻鬼片、近代功夫。它们不能全文叠加；近代功夫强调实体物理，新派武侠强调威亚飞行，聊斋玄幻允许非人空间运动。

## 1. 分类与兼容性

```yaml
classification:
  primary: hybrid_style_profile
  secondary:
    - series_bible
    - production_playbook
  full_series_canon: false
```

### 强适配

- 武侠、奇幻怪谈、仙邪对抗、门派恩怨和近代功夫
- 需要动作、环境介质、色彩和声音共同推动的短片
- 可明确选择一个分支并维护角色、兵器和场景连续性的项目

### 弱适配

- 完全写实历史纪录、现代都市生活、轻喜剧和静态产品片
- 动作没有空间因果、只追求能量爆炸的无结构炫技
- 需要同时保持写实拳法和大规模无重力法术却未说明世界规则的项目

## 2. 共同视听核心

- 写意空间：烟、雾、雨、雪、竹叶、沙尘和纸屑参与构图与动作
- 冷暖或明暗强对照，逆光、剪影和局部框景
- 动作具有明确主体、方向、能量中心、冲击波和环境结果
- 极静对视与极动交锋形成节奏反差
- 兵刃、气流、法术和实体击打构成高辨识度声音层
- 剪辑沿动作方向、撞击点、声音瞬态和能量余势完成

## 3. 三个视觉与动作域

### 新派古典武侠

- 大漠、竹林、孤峰、客栈和江南烟雨等写意空间
- 橘红与幽蓝、翠绿与绯红或素白的高张力冷暖组合
- 斗笠、面纱、残剑、酒坛、枯叶和黄沙作为可选意象
- 威亚式失重飞行、低机位跟拍、高空俯视和极静极动切换
- 表演孤傲、冷峻、含蓄而有杀机

### 聊斋玄幻鬼片

- 荒山古庙、枯木怪石、纸灯笼、符箓、白纱和冥纸
- 幽绿、冷月惨白、深紫暗部与高亮逆光轮廓
- 无重力平滑幽魂视角、畸变广角、倾斜构图和前景遮挡
- 瞬移、分身和符箓力场必须遵循当前世界规则
- 表演妖异、凄冷、空洞或带克制邪魅

### 近代功夫

- 武馆、市井、梅花桩、木人桩、醒狮、长衫和油纸伞
- 黄铜、泥土褐、暖金日光和格窗光影
- 中景与中近景清楚记录底盘、步法、拆招和发劲
- 击打点特写、衣料和尘土反馈突出实体质量
- 表演沉稳刚毅，身体受力和肌肉反应可信

## 4. 上游内容与世界物理

- 先确认分支域；不同域可以作为剧情中的不同地点或状态，但必须显式说明切换原因。
- 正邪可以复杂，人物动机不能因风格被改写成固定侠客、妖女或宗师原型。
- 超常动作需要明确当前世界允许的轻功、法术、瞬移或内力边界。
- 近代功夫默认物理可信，不应无理由加入“虚空二次借力”等玄幻动作。
- 大规模爆破与破坏必须服务剧情，并说明能量来源和环境结果。

## 5. 角色、兵器与场景连续性

- 锁定角色面容、发型、服装、鞋履、标志道具和分支风格。
- 同一兵器保持长度、材质、破损、握持与状态一致。
- 同一场景锁定地形、建筑、植被、天气、介质和光源方向。
- 多角色群战只绑定核心角色，其余群像以明确阵型、方向和层次描述。
- 老片参考的褪色、噪点和化学污迹应与原始艺术意图区分；不把老化脏色当风格。

## 6. 镜头与动作语法

- 通用机位：低角度仰拍、倾斜地平线、极速变焦、甩镜跟随、高空俯视和撞击点特写。
- 动作先明确主体与方向，再描述衣袂、兵器、介质和环境反应。
- 群战要有核心对抗轴、外围阵型和空间层次，避免所有人无目标乱动。
- 法术要有能量中心、扩散方式、受影响物体和落点状态。
- 近代功夫要完整呈现攻防链、底盘、受力和击打反馈。

## 7. 表演

- 新派武侠：冷峻凝视、嘴角轻抿、锐利目标锁定
- 聊斋玄幻：非人静止、幽深眼神、若有若无的邪魅反应
- 近代功夫：沉着、咬牙聚力、太阳穴与肌肉张力随发劲变化
- 爆破和强光反应应与瞳孔、眯眼、呼吸和身体受力同步
- 不机械套用“圆睁、咬牙、青筋”模板，每次表演由角色处境决定

## 8. 声音、对白、旁白与音乐

### 镜头内声音

- 气流破空、衣袂、刀剑出鞘和碰撞
- 法术低鸣、符箓燃烧、力场和失重介质声
- 拳肉、木桩、瓦砾、脚步和环境冲击
- 对白属于镜头内同步声音；旁白属于跨镜独立音轨

### 背景音乐

- 新派武侠：古筝、琵琶、洞箫、战鼓、锣钹和可选无词男声
- 聊斋玄幻：埙、排箫、古琴、环境持续音、木鱼、铜铃和可选无词女声
- 近代功夫：唢呐、板胡、醒狮锣鼓和有实体重量的低频打击
- 配乐方向不依赖具体音乐人或已有歌曲

## 9. 剪辑与音画同步

- 蓄力和对视可延长，交锋用动作点硬切与方向匹配。
- 撞击落实帧、切点、声效瞬态和音乐重音尽量对齐。
- 高速动作可在不同视角保留极短动作重叠，具体帧数属于后期适配。
- 新派武侠强调动静突变；聊斋强调平滑幽魂移动与突发惊悚切换；近代功夫强调拆招连续性和受击点切换。
- 紧张动作中避免无动机淡化；玄幻消失可在有明确物理意图时使用极短材质过渡。

## 10. 负面约束

- 禁止创作者姓名和具体作品成为运行时提示词依赖
- 禁止角色、服装、兵器、场景、音色和动作方向漂移
- 禁止低画质老片褪色、黄化、污迹和噪点污染现代画面
- 禁止没有能量来源和物理结果的随机爆炸
- 禁止近代功夫无理由玄幻化，禁止聊斋幽魂被做成普通人步行抖动
- 禁止随机字幕、水印和无关音乐进入视频素材

## 11. 来源冲突与处理

- 全局规格写目标 720p，视频生成规则又固定 480p；分辨率归入生产适配层，由当前模型能力决定。
- 源文档一处说视频模型可替换，另一处用“推荐”语气；本 Profile 不锁模型。
- 近代功夫示例加入凌空二次借力，与“实体拳法物理质量感”冲突；默认移除，除非当前世界明确允许超常轻功。
- 故事板单镜 5–15 秒与后期 0.5–1.5 秒高速切分并不矛盾，但需要把生成段落与最终剪辑镜头区分记录。
- 具体超分工具、scale、音色模型和 dB 数值均属于生产适配。
