# 风格档案：复古热血少年赛璐璐动画

## 解析结论

这是一份“**复古少年漫画造型 + 赛璐璐平涂 + 热血战斗节奏 + 夸张喜剧反应 + 复古未来机械**”的混合型风格档案。源文档包含大量具体作品、角色、招式和时期标签；规范化后，它们只作为来源分析，不进入生产提示词或原创角色权威设定。

## 适配范围

- 强适配：热血战斗、变身、角色宣传、轻松日常喜剧、复古未来冒险。
- 中等适配：科幻载具、田园奇遇、短篇团队冒险。
- 弱适配：低饱和写实悲剧、微表情主导的真人质感、完全无动作或无角色的抽象片。

## 脚本前置约束

- 可从“人物、目标、阻碍”扩展三幕结构，但扩展建议必须由用户确认。
- 风格时期应在前期选择：圆润轻喜剧、硬朗热血或现代高彩重制。三者不可在同一角色上无理由混用。
- 原创角色是默认安全路线；原作角色、招式、星球、组织和道具不进入可复用风格档案。
- 变身需要蓄力、爆发、稳定三个阶段，高潮前的克制是爆发成立的条件。

## 视听风格规则

### 视觉身份

- 干净黑色轮廓、赛璐璐平面着色、高饱和明亮色彩、两到三级阴影、轻微复古颗粒。
- 早期分支：圆润线条、可爱夸张比例、明亮温暖和喜剧反应。
- 中期分支：硬朗轮廓、夸张肌肉、低仰威压、高反差和高速战斗。
- 后期分支：保留手绘线条和色块，同时增加更细的数字光影与粒子层次。

### 角色与机械

- 角色锁定发型轮廓、颜色、眼睛、体型、服装配色和形态版本。
- 多形态角色分别建档，按发型、瞳色、肌肉、气焰、服装损坏和过渡态保持链式连续。
- 复古未来机械强调圆润曲面、铆钉、接缝、透明舱盖、简单仪表和清楚的主副配色。
- 原创化应改变高辨识度的发型、发色、服装配色和能量颜色组合，不靠一句“原创声明”替代真实视觉差异。

### 场景、动作与摄影

- 场景按前景、中景、背景、建筑、光线和破坏状态描述；破坏程度随战斗推进。
- 战斗动作写清轨迹、身体扭转、重心转移、环境反应和对手反应。
- 热血段常用低仰、鸟瞰、快速横移、冲击线和短促硬切；喜剧段给夸张反应留落地时间。
- 同一场景维护轴线、屏幕方位、光色和破坏状态；高难动作可用相邻镜头终态衔接。

### 声音与音乐

- 能量、冲击、碎石、雷电和环境反应声与动作节点同步。
- 战斗音乐可高能，日常音乐可轻快；不得使用具体作品主题曲或知名艺人名称。
- 台词必须与身体表演、语速、停顿和音色连续性对齐。

## 生产层路由

- 角色三视图、多形态链式图、场景四宫格、载具图、模型、清晰度、时长、声音样本、占位符和适配器语法均归生产层。
- 招式模板和大量专名替换表是生产参考，不是风格权威设定；正式使用时应从原创动作目的重新描述。

- 源文档一方面声称可涵盖具体作品与角色，另一方面又要求提示词不得出现作者、作品和角色名；正式风格档案应只保留通用视觉技法和原创化要求。
