# 风格档案：狂暴废土公路歌剧

## 解析结论

这是一份以**高速公路追逐、人格化拼装机械、资源崇拜、歌剧式牺牲、中心构图和物理爆点剪辑**为核心的混合型风格档案。它的价值不在“满屏铁锈、钢刺、火球”，而在明确用途、轮廓差异、受力位置、动作因果和节奏阶梯，使极端混乱仍然保持可读。

源标题所指导演与具体影片只用于来源追踪。正式生产应使用原创部落、载具、资源信仰和誓词，不复刻角色、车辆、台词或标志装置。

## 脚本前置约束

- 可选结构为荒凉秩序 → 仪式集结 → 公路追击 → 牺牲或烈火高潮。
- 核心主题可围绕资源控制、信仰操控、群体狂热、生存与自由，但必须来自当前故事，不自动套用经典设定。
- 原型角色、口号和资源崇拜只是示例；应根据用户大纲创造新的部落外观、资源体系和仪式语言。

## 视听风格规则

### 视觉身份与色彩

- 沙漠橙、铁锈红、金黄热浪与局部青蓝天空或冷钢阴影形成强对比，但不能把青橙当成覆盖全片的滤镜。
- 日景、沙暴、黄昏、夜景和据点内部各有独立光色逻辑；所有光束、火焰反光和烟尘必须有物理来源。
- 前景展示粗糙机械材质，中景保持动作主体清楚，远景降低对比与锐度形成大气透视。
- 禁止赛博霓虹、数字故障、全屏光晕、过度锐化和电子游戏式持续速度线。

### 机械与材质

- 每辆载具先定义战术用途、体量、轮廓、轮胎或履带结构和运动姿态，再选择 2–3 个识别特征。
- 磨损按功能与受力分布：前防撞区、侧翼接触面、轮罩下缘、排气口等各有不同痕迹，非受力区保持相对克制。
- 材料需可辨认：氧化钢、裸铝、旧橡胶、开裂皮革、油污布料、麻绳和透明防护板。
- 普通行驶不自动出现火花、黑烟、沙暴与爆炸；每个爆点集中表现一种主要特效，并交代原因与结果。

### 人物、表演与声音

- 人物以风化皮肤、油脂、沙尘、护具、呼吸装置和部落妆容建立身份，不依赖具体原作角色。
- 高压凝视、喘息、仪式涂装和群体回应可建立狂热，但誓词必须原创。
- 旁白可采用沙哑、粗粝、低沉、疲惫的生存者声线，语速慢、留白大，不用播音腔煽情。
- 引擎、机械增压、金属刮擦、轮胎、沙暴、排风扇和高压漏气构成主要声场；工业摇滚只是一种可选音乐方向。

### 摄影与剪辑

- 高速平行追踪、贴地低机位、爆点急推、高频横移与视差拉扯是核心镜头语言。
- 常态行驶保持可读和克制；只在碰撞、爆炸或极端颠簸的一瞬触发强烈震动，并快速阻尼回正。
- 快切时将角色眼睛、车辆中轴、发动机或武器落点尽量保持在相近视觉中心，降低视线漂移。
- 节奏从蓄势、递进到爆点，再用较长镜头释放；沙尘遮挡、瞬时过曝和甩镜可以成为物理转场。
- 定格、慢动作、抽帧和混合变速只用于明确爆点，不应全片滥用。

## 连续性规则

- 同一载具的装甲、排气、轮胎、损坏位置和烟尘来源跨镜稳定。
- 碰撞前因、接触点、受力方向、损坏结果和后续操控状态形成连续链。
- 场景参考、角色、车辆、道具、台词和声效在生产前逐项对齐故事板。

## 生产层路由
