## 0. 解析结论

这份源文档不是单一“女友／男友视觉风格”，而是 **第一人称互动内容 Bible + 单主体视听风格 + 生产与宣发流程手册**。最可复用的视听核心是：

- 镜头就是观察者的眼睛，主体持续与镜头建立关系；
- 画面只出现一个完整主体，观察者最多以有物理依据的局部手部或袖口出现；
- 近距离手持主观镜头、浅景深、自然呼吸感和直接眼神交流；
- 微表情、动作、空间距离与声音共同形成情绪递进；
- 台词、环境声、衣物摩擦与呼吸等近距离声音强调在场感；
- 单段内部倾向连续表演，跨段通过姿态、光线、声音和情绪状态承接；
- 互动必须自愿、非露骨、无胁迫，并严格区分成人恋爱与非人类陪伴域。

源文档标题暗示“女友／男友”，但正文明确不支持男性人像主体；因此本档案不能宣称男女主体都已定义。它目前只对 **成年女性恋爱主体** 定义较完整，对动物和 IP 只保留非恋爱陪伴互动，对男性主体保持未定义。

## 2. 内容域必须互斥

### 2.1 成年女性恋爱互动域

- 主体必须明确为 18 岁以上成年人；
- 关系基于自愿、平等、温馨、调皮或甜蜜；
- 可以有暧昧气氛、近距离眼神和非露骨亲昵；
- 禁止裸露、性行为、胁迫、失去意识、露骨身体聚焦和前戏暗示；
- 禁止用可识别真实公众人物作为亲密内容原型。

### 2.2 动物陪伴互动域

- 只加载抚摸、喂食、玩具逗弄、仰望镜头、靠近镜头等陪伴行为；
- 不加载恋爱关系、同居情侣预设、暧昧台词、成人昵称和身体张力规则；
- 声音以动物发声、环境声和观察者轻声互动为主。

### 2.3 IP／玩偶陪伴互动域

- 只加载挥手、歪头、点头、被轻触后的回应、递物等非恋爱互动；
- 保持原始造型风格与材质；
- 不自动套用成年女性的妆造、服装、亲密动作或关系台词。

### 2.4 男性主体域

源文档没有定义男性主体的造型、表演与关系规则，并明确要求中止。因此当前版本标记为 `blocked`；若未来要支持，需要独立补充并重新审核，不能只改标题。

## 3. 适配范围

### 强适配

- 成年女性与镜头观察者之间的温馨、日常、调皮第一人称互动；
- 单只宠物或单个 IP 角色面向镜头的陪伴型互动；
- 需要强代入、直视镜头、近距离微表演和声音细节的竖屏短片。

### 中等适配

- 主体面对镜头的生活 Vlog、角色问候、轻剧情互动；
- 无恋爱设定的第一人称照护、游戏或陪伴片段。

### 弱适配

- 多主体同框；
- 第三人称客观叙事；
- 动作大片、复杂群戏或需要大量环境展示的作品；
- 依赖完整观察者表演的双人戏。

### 兼容性门

脚本若需要第二个完整人物同框、强制控制、露骨性内容或未成年人恋爱化表达，判定为不兼容；不得通过镜头裁切掩盖内容冲突。

## 5. 主观镜头与单主体构图

### 主观镜头

- 摄像机等同观察者视线；
- 运动来自走近、坐下、转头、轻微呼吸或自然手持；
- 主体直视镜头即直视观察者；
- 禁止突然切成旁观者看两人的第三人称镜头。

### 单主体锁

- 画面内始终只有一个完整主体；
- 观察者可不入画；
- 若互动需要观察者肢体，只允许画面边缘的局部手、前臂或袖口，并保持真实连接方向；
- 禁止漂浮断肢、完整第二人物、第二张脸、大面积腿部或躯干入画；
- 非人主体同样适用单主体锁。

### 空间距离

- 开场先建立主体与环境；
- 互动发生后缓慢缩短距离；
- 情绪顶点可进入面部近景，但保留可辨环境和安全空间；
- 不用遮挡镜头、对镜头哈气或无动机极端失焦制造亲密感。

## 6. 视觉身份

### 全局视觉 DNA

- 主观在场感；
- 一个清晰主体；
- 直接眼神交流；
- 近距离微表演；
- 自然或情绪化环境光；
- 浅景深但主体边缘与手部关系可读；
- 轻微手持呼吸感，而非剧烈摇晃。

### 四种成人互动气氛

#### 暧昧灵动

- 高调柔光、浅色服装、轻快小动作；
- 视线先回避再回到镜头；
- 声音轻、气息近、句尾略上扬；
- 禁止用露骨动作代替情绪。

#### 微醺夜色

- 低调暗光、局部高饱和反光、持续眼神联系；
- “微醺”只描述环境和妆造氛围，不得表现失去判断能力或非自愿状态。

#### 日常温馨

- 暖色生活空间、自然动作、真实笑容与细小生活声；
- 适合递物、一起做饭、整理衣领、沙发闲聊等低风险互动。

#### 强势张力

- 冷暖分割光、深色服装、较慢语速和稳定直视；
- 强度只落在眼神、距离和语气；
- 不延伸为压制、强迫、控制或限制行动。

---

## 7. 微表演语言

### 眼部

- 视线回避后缓慢回望；
- 睫毛轻颤；
- 眼尾轻扬；
- 瞳孔和眼神变化须克制，不使用夸张特效。

### 唇部与表情

- 嘴角单侧轻扬；
- 短暂抿唇、嘟嘴或轻咬下唇；
- 表情变化与台词或观察者动作形成因果；
- 不对嘴唇和身体部位进行色情化特写。

### 肢体

- 身体重心前倾或后撤；
- 撩发、整理衣物、递物、牵手或轻触手腕；
- 每段优先选择不同互动动作，避免反复摸脸和贴耳低语；
- 复杂接触需简化为模型可执行、构图安全且自愿的动作。

### 非人主体适配

- 动物：耳朵、尾巴、鼻尖、步态、仰头和靠近动作；
- IP：歪头、点头、挥手、捧物和材质形变；
- 禁止把女性人物的微表情与身体动作机械套用到非人主体。

## 8. 节奏与连续性

源文档的单段结构可作为叙事参考，而非固定秒数：

1. **建立**：环境、主体初始状态、与镜头的距离；
2. **互动契机**：视线、台词或轻动作建立关系；
3. **情绪升温**：观察者以镜头位移、声音或局部肢体回应；
4. **余韵**：主体靠近、停顿或用一句台词收束。

多段连续性至少锁定：

- 主体身份、服装、妆容、发型或非人外形；
- 场景、主光方向和色温；
- 上一段结束姿态与下一段起始动作；
- 情绪弧线只能推进或有解释地回落；
- 声音距离、环境声和整体响度。

固定 30 秒和逐 0.5 秒时间轴属于生产参考，由当前时长预算重算。

## 9. 声音身份

- 声音应让观众感觉主体与观察者处于同一近距离空间；
- 台词、呼吸、衣物摩擦、雨声、风声和室内底噪保持距离关系；
- 贴耳低语只在有动机时少量使用；
- 人声清晰，不被环境或音乐覆盖；
- 是否由视频模型内嵌生成不是风格规则；
- 配乐可有可无，不能同时写“内嵌全部声音”和无条件 `no music`；由当前项目明确选择。

源文档没有提供稳定的跨项目声音角色档案，因此具体音高、音色、口音与语速保持为空，运行时再提案。

## 13. 源文档冲突与处理

1. **标题支持女友／男友，正文禁止男性主体**：当前版本只支持成年女性恋爱主体；男性域标记阻塞。
2. **成人、动物和 IP 共用一个关系模板**：强制拆成互斥内容域，动物与 IP 不加载恋爱规则。
3. **两个视频模型选项名称与规格重复**：视为文案错误，不进入档案。
4. **“全部声音内嵌”与默认 `no music` 并存**：运行时单独决定是否有音乐，不能两者同时作为硬规则。
5. **部分互动例子与自愿／非露骨边界张力过高**：不提升为 Style Core；以安全边界和简化动作优先。
6. **自动补全可能发明服装和亲密程度**：改为只补环境感官建议，关系和亲密动作必须有明确依据。
7. **“同居热恋”被写成全局默认**：降为可选系列前提，不自动应用。
