## 0. 解析结论

这不是单纯的画面风格，而是一份以“玄幻国漫武打”为核心的**混合视听风格档案**。它同时包含动作导演语法、跨镜连续性、空间锚定、物理反馈、声画强拍和生产流程。

最值得固化为长期风格规则的部分是：

- 打斗必须由身体动作驱动，玄幻能力依附于脚步、掌心、刃口、法器、护罩、地面或环境媒介。
- 每次交锋必须有攻防因果，不能只让角色站桩放光。
- 特效必须与衣物、烟尘、碎石、水波、地面和光源发生可读的物理互动。
- 镜头必须让观众看清起手、接触、命中或近命中、结果反馈。
- 镜内与镜间状态持续推进，角色、武器、法术、战损和场景破坏不得无原因复位。
- 画面追求清晰的玄幻国漫 / 漫剧质感，而不是高密度粒子、全屏辉光或不可读的“炫技”。

源文档中的具体模型、分辨率、画幅、参考帧流程、确认节点和提示词包装均属于后续生产适配层，不是永久风格身份。

## 2. 适配范围

### 强适配

- 玄幻国漫、漫剧、仙侠和神魔短剧
- 30–60 秒的独立动作段落
- 压迫、试探、追击、救人、破阵、觉醒、反杀、立威或逃生
- 武器、法器、护体、阵法与环境发生明确交互的战斗
- 需要“先看懂，再震撼”的高可读性动作

### 弱适配

- 纯对白、慢生活、治愈日常
- 完全写实且无奇幻机制的格斗纪录
- 依赖大规模群战、复杂多人同步动作的低预算视频
- 以全屏光柱、粒子海或抽象能量为主要卖点的奇观视频

## 3. 前置内容模块

Style Profile 不拥有选题和剧本语义，只提供以下软约束：

- 在剧本阶段先明确这场打斗的戏剧功能，而不是先堆招式。
- 明确强弱关系：谁占上风、谁被压制、谁试探、谁隐藏实力、谁保护或逃生。
- 能力体系至少要能回答触发方式、作用对象、持续状态和可见后果。
- 若剧本已冻结，新增风格规则不得反向改写 Hook、Reveal、事实或核心结论。

## 4. 视觉身份

### 画面核心

- 清晰玄幻国漫 / 漫剧质感
- 角色轮廓清楚，材质分层明确
- 渲染表面干净，不产生脏灰和蜡化涂抹
- 中高明度，低至中等饱和
- 冷暖有主次，暗部保留纹理
- 能力特效受控，不能遮住身体动作、接触点、武器方向和受击姿态

### 环境媒介

优先让能力反馈落在可见媒介上：

- 烟尘、碎石、霜晶、雨水、水波
- 衣袍、发丝、树叶、旗帜
- 地面裂纹、阵纹、墙面和建筑构件
- 护体光罩、法相或结界的破裂、消散、反噬与余波

环境不是背景贴图，而是动作结果的证据。

## 5. 动作导演语法

### 单镜核心链

每个核心镜头都必须能用一句话回答：

> 谁发动 → 如何发力 → 对方如何防守或闪避 → 如何反击、命中或近命中 → 对方如何承受 → 环境如何响应。

### 复杂度上限

每个镜头优先只保留：

- 一个主要身体动作
- 一个玄幻能力机制
- 一个环境反馈重点
- 一个明确结束状态

复杂度过高时，先删除次要奇观，不删除动作因果和结果反馈。

### 镜内节拍

推荐结构：

1. 起手：中景或中全景交代站位、距离和攻击轴线。
2. 接触：特写交代手、脚、兵器、法器、护罩或阵纹。
3. 命中 / 近命中：关键强拍可短暂震动、冲击帧、慢动作或听觉真空。
4. 结果：回到可读景别，看清谁退、谁稳、谁失去道具以及环境如何改变。

不能让所有攻击都命中；闪避、格挡、落空、反制、喘息和结果反馈应交替出现。

## 6. 摄影与剪辑

### 推荐

- 中景或中全景建立空间
- 接触点特写
- 关键强拍短促推拉、冲击震动或甩镜
- 动作点硬切
- 落点后保留短暂余势，让衣袍、烟尘、碎石、霜晶或兵器震颤继续运动

### 避免

- 全程手持乱晃
- 全程慢动作
- 特效替代动作
- 接触特写之后没有结果镜头
- 用快切掩盖站位跳变或物理断裂
- 为追求奇观而让主体轮廓不可辨

## 7. 角色、场景与道具

### 角色视觉

需要锁定面部、发型、服装层次、材质、代表色、身法、能力属性和阶段状态。觉醒、战损、脱力或形态变化应作为同一角色的状态变化记录，不应被当成新角色随意重绘。

### 场景

同一场战斗优先复用同一空间。至少记录：

- 固定参照物
- 前、中、后景关系
- 四向空间信息
- 主光源方向和色温
- 攻击轴线与退路
- 可借力点、可破坏物和动态媒介

### 武器与法器

核心道具必须持续记录持有者、握持手、握持点、方向、展开或收拢、离手轨迹、落点、破损与发光状态。任何变化都需要可见触发。

## 8. 连续性

### 镜间连续

下一镜开始状态必须由上一镜结束状态推出，至少继承：

- 人物位置、姿态、朝向和距离
- 武器 / 法器归属和方向
- 能力、护体、结界或法相状态
- 战损、受伤、场景破坏
- 烟尘、裂纹、水波、碎石等环境残留
- 主光源与场景空间

### 镜内连续

每个动作节拍都把上一节拍的结果作为输入。已经离手的武器不能自行回手，已经破裂的护罩不能无原因恢复，已经改变的站位不能在后半段复位。

### 冲突处理

出现连续性问题时，先修正状态链和物理因果；不要通过堆叠更多负面词掩盖结构错误。

## 9. 表演、声音与音乐

### 表演

- 强弱关系通过站位、攻击比例、受击反馈、角度和景别体现。
- 情绪用眼神、呼吸、肌肉紧张、嘴角、鼻翼和身体姿态表达。
- 避免只写抽象心理或夸张面相词。

### 声音设计

- 破空、兵器碰撞、法器共鸣、碎石、衣袍、喘息和环境声应对齐动作节点。
- 关键碰撞可短暂抽空其他声音，形成听觉真空。
- 声音必须区分起音、冲击峰值和余韵。
- 若使用独立配乐，配乐不得盖过碰撞、对白、喘息和空间声。

### 音乐

源文档没有固定配器 Canon。可根据打斗功能选择压迫、递进或爆发型配乐；具体乐器、模型和生成方式属于运行时决策。

## 11. 核心负面约束

- 不要站桩放光
- 不要动作与特效脱节
- 不要全屏辉光、纯黑或过曝白
- 不要粒子遮挡脸、身体、武器和接触点
- 不要道具归属、方向、尺寸或落点突变
- 不要镜内或镜间状态复位
- 不要没有防守、闪避、受击或环境反馈的单向攻击
- 不要用随机镜头漂移代替动作设计
- 不要血腥细节和肢体猎奇

## 12. 缺失项与待审问题

- 没有完整音乐配器系统。
- 默认 16:9、30–60 秒和具体模型属于来源工作流，不应覆盖项目规格。
- “一键生成”与“逐镜确认”是生产选项，不是风格属性。
