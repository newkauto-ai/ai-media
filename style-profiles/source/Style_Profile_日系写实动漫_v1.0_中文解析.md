# 风格档案：日系写实青春光影动画

## 解析结论

这是一份以**现实空间可信度、物理光源、克制表演、多机位连续性和高密度自然对白**为核心的视听风格。它适合青春关系、城市生活、错过与重逢等近现实情感题材。风格重点不是“漂亮动漫滤镜”，而是让人物、光线、空间、动作和声音都具有可追踪的因果关系。

源文档中的具体模型、清晰度、单镜时长、资产格式与生成失败回退属于生产层；“默认无音乐、无字幕、无旁白”是该源方案的强偏好，但不应覆盖当前项目的明确需求。

## 适配范围

### 强适配

- 青春关系、都市相遇、错过、重逢、成长与告别。
- 电车、雨天玻璃、黄昏天台、星空、云海等日常空间中的情绪叙事。
- 依靠视线、停顿、呼吸和对白推进的双人或小群像短片。

### 弱适配

- 依赖夸张肢体喜剧、强烈怪诞变形或持续高速动作的题材。
- 需要宏大配乐主导、字幕主导或大量说明性旁白的内容。
- 无法锁定场景光源、人物位置与动作连续性的快速拼接项目。

## 脚本前置约束

### 直接提取

- 完整剧本优先忠实解析，不擅自改写核心情节；只有一句灵感时，扩展内容必须标记为待核实。
- 对白语言与口音会改变节奏、语气词和表演方式，应在脚本冻结前确定。
- 情绪表达以克制、含蓄、自然口语为准，避免持续嘶吼、失控哭喊和夸张肢体宣泄。

### 路由说明

- 对白语言、叙事主题和情绪强度属于脚本层。
- “无音乐、无字幕、无旁白”若与当前视频需求冲突，应记录为风格冲突，不能静默覆盖已冻结脚本。

## 视听风格规则

### 视觉身份

- **直接提取**：日式写实动漫质感；通透但不塑料；细腻环境细节；光影必须有可见或可推断的物理来源。
- **结构归纳**：真实空间逻辑与动画美化并存。人物仍是动画角色，但皮肤冷暖、发丝透光、眼周与唇部纹理、手部关节和服装材质应保留微小生命感。
- 禁止真人照片化、过度磨皮、塑胶皮肤、无来源外发光、平涂无材质和均匀环境光。

### 色彩与光线

- 黄昏以橙金主光、蓝紫天空和拉长阴影形成冷暖关系。
- 雨景强调玻璃雨滴、滑痕、反射和背景虚化；星空与云海必须有空间层次，而非装饰贴图。
- 暗部保留材质，亮部保留纹理；相邻镜头的主光方向、色温和阴影方向保持连续。

### 角色与表演

- 眼睛保留少量星点高光；逆光发丝呈分组半透明；肤色有自然冷暖变化。
- 表演顺序优先为：开口前微反应 → 呼吸或视线变化 → 动作 → 台词 → 收束。
- 悲伤、愤怒、恐惧和温柔均落到眼睑、下颌、嘴唇、呼吸和姿态等可见信号，不直接依赖情绪标签。

### 摄影与剪辑

- 使用远景、全景、中景、近景和特写形成有意图的递进；相邻镜头避免重复机位和景别。
- 对话优先肩后、正反打和视线切换；人物正面机位保留一定偏转，避免无动机正面定止。
- 镜头允许克制的手持呼吸、缓慢横移、跟拍或有加减速的推拉；禁止机械匀速、无目的炫技和长时间完全静止。
- 连续性锁定 30° 规则、动作匹配、视线、屏幕方向、人物位置、道具状态与光色。

### 声音与音乐

- 环境声以雨、电车、蝉鸣、风等具体空间声音为主，并服务对白清晰度。
- 源方案不设计背景音乐；若当前视频需要音乐，应作为用户覆盖或运行时决策，并保持克制，不替代对白与环境声。

## 生产层路由

- 角色身份板、场景多视角参考、资产绑定、音色参考、视频参考数量、模型选择、分辨率与失败回退全部进入生产层。
- 生产提示词应按“参考用途 → 起始状态 → 摄影 → 表演 → 光线与环境 → 对白和声音 → 终止状态”编译，但不把占位符或旧工具语法写入永久风格身份。

## 冲突与待审阅项

- “所有镜头不得完全静止超过 1.5 秒”属于强生产指标，不适合永久硬编码；静止是否失效应以叙事功能判断。
- “至少四种机位、至少三类视觉母题”等数量阈值更适合作为当前项目质量检查建议。
- 默认 16:9、每秒 24 帧、无音乐、无字幕、无旁白均需接受当前视频规格覆盖。
