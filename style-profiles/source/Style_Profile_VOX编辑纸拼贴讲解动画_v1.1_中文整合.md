# Style Profile：VOX 编辑纸拼贴讲解动画

> **正式调用 ID**：`vox_transcript_driven_handmade_collage`  
> **常用称呼**：VOX 拼贴动画、编辑纸拼贴、逐字稿驱动手作拼贴动画  
> **升级原则**：整合现有档案与 `vox-director` 的可复用创作方法；不复制其独立 Skill、供应商流程或执行脚本。

## 适用范围

- 适合把讲解、历史、商业、产品或观点型内容转成旁白驱动的编辑纸拼贴短片。
- 每个 Beat 只承担一个可复述的信息点、转折或证据；用一个主视觉隐喻和少量有功能的纸片元素表达。
- 事实、论点、CTA 和叙事顺序继续由 Topic / Script owner 决定；本档案只规定如何看见、听见和组织这些内容。
- 纯装饰拼贴、连续写实表演、需要真实空间物理连续性的场景不是默认适用项，应先做兼容性判断。

## 风格核心：先做完整海报，再决定怎么动

- 每个 Beat 先形成一张信息完整、构图成立的分层拼贴海报。动效不能挽救层次薄弱、信息混乱或只是“贴纸堆叠”的静帧。
- 海报必须能辨认前景、中景、背景和独立纸片：主体、道具、标题条、报纸碎片或几何装饰各有清楚边缘、材质差异和纸层投影。
- 跨 Beat 固定纸张触感、裁切语言、半调密度、标题层级和总体时代语汇；主题色和局部素材可随叙事推进变化。
- 默认保持正面或近似扫描件的二维观看关系；纸层可以产生轻微景深和视差，但不能漂成光滑三维渲染。

## LOOK 轴

每个项目从以下轴各作一个明确选择，并在同一成片内保持一致；具体取值由当前主题和已批准参考决定，不建立第二套主题库。

- **媒介**：手剪或撕纸、摄影剪贴、报纸印刷、丝网/孔版印刷、复印机颗粒、木刻或平涂插画中的一种主语言。
- **时代与设计语汇**：例如现代编辑、国际主义网格、构成主义、朋克小志、装饰艺术或在地文化印刷传统；不得仅为“好看”混搭互相冲突的年代语汇。
- **构图**：明确海报层级、焦点、留白和阅读方向；一个主角或主对象，卫星元素只用于强化主题、建立语境或平衡版面。
- **色彩**：优先有限色板、单一平涂底色和一个强调色；允许色彩沿叙事弧推进，但避免泥化渐变和每段无关联换色。
- **字体与文字**：标题作为设计资产处理，短、粗、层级清楚；逐字核对拼写。关键事实、品牌名和长字幕优先保留为后期可控文字层，而非交给视频模型重绘。
- **纸面质感**：可见纤维、毛边、折痕、轻微套印错位、胶带、半调网点和真实纸层阴影；质感服务层次，不覆盖人脸、产品标签或关键信息。

## Beat 与镜头组织

- 一个 Beat 对应一个核心信息单元和一张主海报；需要更强节奏时，同一 Beat 可派生“建立画面 + 细节切入”，但两镜必须共享同一信息目标和视觉身份。
- 开头直接展示承诺、反差、问题或关键事实，不用空泛的品牌片头消耗注意力。
- 相邻 Beat 应有可感知的构图、焦点、色彩或纸片状态变化；变化频率由目标时长和平台决定，不写死秒数。
- 运镜在相邻镜头间避免机械重复；静止或近静止应留给结论、数字、引语或兑现点，让节奏下降本身成为强调。
- 视觉双关必须忠实于原稿；不能为了制造奇观改变事实、因果或人物立场。

## 两条动效路线

### A. 会动的海报（默认、低成本）

- 以完整海报为视觉基线，只做一个清楚的镜头运动，并让刚性纸层产生轻微漂移、滑动、摆动、翻页、脉动或视差。
- 元素运动可以丰富，但必须各自服务本 Beat；避免所有碎片同时随机飞行。
- 文字、Logo、人物面部、产品外形和标签保持稳定；运动远离关键文字区，结束时落到清楚、可读的状态。
- 避免纸片弯曲、融化、变形、突然改景、镜内跳切和无动机透视旋转。

### B. 拆件组装（高控制、高投入）

- 仅在“碎片逐件进入并还原成主海报”本身是关键看点，或真实人物/品牌资产需要像素级锁定时使用。
- 每个元素的终点必须回到已批准海报中的原位置；不能把拆件后重新摆放成另一张版式。
- 入场可用飞入、拍入、落下、弹入和轻微过冲，但先后顺序必须建立阅读路径；最终停稳并兑现完整海报。
- 拆件、清理遮挡、补背景和逐件编排属于生产成本；应由当前项目在生产层选择实现方式，不能把某个本地引擎当作风格硬依赖。

## 人物、产品与真实素材锁定

- 使用真人照片或产品图时，把主体视为摄影贴纸锚点；保留身份、表情、产品轮廓、材质反光、Logo 和标签文字。
- 插画化、半调或纸纹只作用于主体之外的纸片世界，除非用户明确批准对主体本身的重绘。
- 人物动作优先由纸偶身体、手势或周围元素表达，不通过重绘脸部制造新表情。
- 视频阶段仍需抽帧复核人脸、Logo 和每个关键字；“静帧正确”不等于“动起来仍正确”。

## 声音方向

- 讲解型成片由单一、连续的旁白承担信息主线；画面、标题和音效不重复塞入同一层信息。
- 音乐以器乐节奏和编辑感为主，在旁白下让位；纸张拍入、撕裂、翻页和印章声只同步关键可见动作。
- 若项目本身是无旁白的视觉短片，可省略旁白，但必须由画面内状态变化独立完成信息传递。

## 失败判据

- 静帧像扁平 PPT、贴纸合集或光滑 CGI，而非具有纸层、印刷和编辑层级的完整海报。
- 每个 Beat 同构、同运镜、同节奏，只有文案和底色变化。
- 标题抖动、拼写漂移、人物身份或产品标签被重绘。
- 一个镜头同时要求多种相机运动、复杂时间线和大幅元素变形，导致画面失稳。
- 组装路线没有回到原海报，或元素入场顺序不能建立信息阅读路径。
- 拼贴元素有装饰性但没有叙事功能，视觉隐喻改变了原稿事实或因果。

## 生产层边界

- 模型、供应商、API key、分辨率、画幅、固定时长、帧率、费用、自动重试、字幕烧录、混音命令和导出工具都由当前 Adapter / Prompt Compiler / Gate 决定。
- 不引入 `beats.json`、Atlas Cloud、ffmpeg、本地拆件引擎或新的审批 Gate 作为本档案的依赖。
- 现有 `selected_style_profiles`、Controller、Audiovisual Director、Video Production、Review 和 retry 机制保持唯一 owner。
