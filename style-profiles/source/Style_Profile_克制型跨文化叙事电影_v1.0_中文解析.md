# 风格档案：克制型跨文化叙事电影

## 解析结论

源文档不是一个单一视觉风格，而是一个以“克制、留白、秩序与内在张力”为共同母核的**四分支风格族**：家庭伦理、写意武侠、古典悲剧和哲学奇观。若不先选择分支，色彩、动作、音乐与剪辑规则会互相冲突，因此该风格档案在进入制作前必须完成分支选择。

标题中的导演姓名仅用于来源识别。生产时应使用本文件中的可观察特征，不以在世导演姓名或具体影片名称作为直接模仿指令。

## 共同风格母核

- 情绪不直说，通过眼神回避、动作停顿、器物触碰、空间框景与声音留白外化。
- 构图有古典秩序，常用门窗、屏风、纱帘、镜面等形成框中框。
- 自然光或有明确来源的生活光优先；色彩服务人物内在状态，不追求无动机炫目。
- 摄影与剪辑从容，允许空镜、长停顿和声音桥；关键冲突处可用冷酷硬切。
- 服装、食物、书信、手帕、相框、长剑等道具不仅是装饰，而是人物关系和情绪压力的载体。

## 四个风格分支

### 家庭伦理与文化碰撞

- **主题倾向**：代际、家庭秩序、传统责任与个人选择之间的冲突。
- **空间**：餐桌、厨房、门廊、梁柱和家庭室内；人物被空间几何关系约束。
- **色彩与光线**：温暖生活光、中性灰、窗边侧光、台灯漫射；食物、茶汽和器皿提供细小暖色焦点。
- **表演与声音**：夹菜停顿、摩挲杯沿、回避视线、碗筷轻碰和倒茶声承载心理暗流。

### 写意武侠与东方留白

- **主题倾向**：责任与欲望、克制与挣扎、行动与静止。
- **空间**：竹林、云海、古道、山水与雾；人物在大环境中尺度较小。
- **色彩与材质**：低饱和青蓝、灰绿、白墙黑瓦、宣纸般哑光和雾气留白。
- **动作**：轻盈、缓慢、分阶段、有起势和落地缓冲；镜头与人物位移同向，避免失重滑行和道具变形。

### 古典悲剧与压抑情感

- **主题倾向**：情感受到时代、阶级、道德或环境压制。
- **空间与构图**：狭窄门窗框景对照辽阔荒原、雪山或雨巷。
- **色彩与光线**：冷蓝、灰绿、深褐和雾灰为主，少量烛光、壁炉或台灯暖色作为短暂温存。
- **表演**：长时间微表情特写、嘴角和眼睑轻颤、视线缓慢避开、动作高阻尼。

### 哲学奇观与灵魂审视

- **主题倾向**：信仰、自我认同、生存与和解。
- **视觉意象**：发光水面、无垠星空、镜像自我、双重曝光、悬浮水滴和客观现实与幻觉的并置。
- **构图与运动**：严格对称、居中平衡、缓慢主观推进、俯瞰镜面水面；超现实元素仍保持流体阻力、表面张力和惯性。
- **声音**：空灵人声、低密度环境合成、微小水声与风铃感音效，避免宏大轰炸式管弦乐。

## 脚本前置约束

- 风格分支必须在脚本冻结前选择；不同分支对主题、空间和叙事重心有明显影响。
- 台词与旁白惜墨如金，沉默是叙事资源；但不能因“克制”删除钩子、核心事实或结论。
- 家庭伦理、武侠、悲剧和哲学奇观中的故事模板仅为适配方向，不是自动生成剧情的许可证。

## 连续性与声音规则

- 同一空间锁定场景结构、光线方向、道具位置和人物关系轴线。
- 刚性道具保持几何边界；纸张和织物以褶皱、折痕和受力阴影表现形变，不与手部融合。
- 人声出现时音乐主动避让；句间空白可适度抬高环境声。声音先入与声音延续剪辑可用于衔接生活声、风声、琴声或乐器尾音。

## 生产层路由

- 三视图、四宫格场景、道具材质卡、参考绑定、模型、分辨率、超分、帧率和提示词占位符全部进入生产层。
- 源文档中的百分比调色、具体胶片名称、镜头秒数和分贝值只能作为运行时建议，需由当前摄影、调色与混音方案验证。

## 冲突与待审阅项

- 四个分支不可同时全量启用；必须选择一个主分支，其他分支只能按明确目的借用少量模块。
- 源文档把部分“避免模型失败”的提示词技巧写成审美规则，应在正式机器规范化时继续剥离。
- 高帧率和超分只属于哲学奇观分支的旧生产建议，不是该风格族的共同身份。
