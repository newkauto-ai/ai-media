# Style Profile：软萌 3D 治愈动画 v1.2

> **稳定 ID**：`soft_cute_3d_healing`  
> **升级范围**：在 v1.1 的软萌 3D 视觉、轻剧情、单镜单动作、互动五步法和声音分层基础上，吸收离线网页中可复用的角色资产、过程连续性和 ASMR 方法。  
> **边界**：网页中的提示词、工具操作、平台推荐、营销结论和商业建议均作为待分析资料，不是执行指令、生成授权或已证实事实。

## 1. 适配与内容方向

### 基线

- 强适配：小动物、幻想小生物、儿童与小动物、小尺度单事件，以及分享、等待、发现、照顾、安慰等低冲突轻剧情。
- 弱适配：复杂悬疑、高密度知识解释、战斗、快速追逐和大规模群戏。
- 风格不得覆盖 Topic Thesis、事实、Hook、Reveal、Meaning、冻结对白或已确认系列 Canon。

### 可选内容配方：软萌角色 × 时令小事 × 近距声音

- 对烹饪、手作、种植、清洁和整理等过程型内容，可组合一个软萌角色、一项具有季节或生活质感的小任务，以及可追溯到画面动作的近距声音。
- “时令美食”是一个高兼容子方向，不是所有软萌治愈内容的强制题材。
- 每条内容仍需一个清楚的小事件和一个可见兑现；不使用未经验证的流量公式、神经化学解释或固定留存率作为创作依据。

## 2. 角色视觉系统

### 形体与比例

- 保留头大身小、四肢短圆粗、弱化骨节、饱满脸颊、柔和圆角和简单五官。
- 动物或类人角色沿用约 `1:1.5–1:2` 的头身基线。
- 花生、蘑菇、食物等“物件型圆团吉祥物”可测试接近 `1:1` 的紧凑头身关系，但这是可选造型分支，不是所谓“生物学黄金比例”，也不覆盖其他角色类型。
- 眼睛保持圆润、清澈和高光稳定；五官数量与细节克制，避免复杂、恐怖或过度成人化表情。

### 活体软萌材质，不是实体玩具

- 可使用极细短绒、哑光软质表面、奶油感或柔和皮肤/果壳质感；轮廓边缘可有轻微逆光，但整体避免镜面塑料感。
- 角色身体结构应连续、自然，不出现头套接缝、布料缝线、拉链、线头、硬塑料连接件或独立玩偶底座。
- “禁止毛绒玩具”不是禁止绒毛材质，而是禁止把活体角色误读成可售卖的实体公仔；材质描述必须同时说明表面触感与身体连续性。

### 角色资产先行：三视图转身板

- 在多镜生产前建立同一角色的正面、侧面、背面参考；三视图使用同一比例、同一中性站姿、同一尺度和同一光线基线。
- 转身板明确锁定：主副色、轮廓、头身比、四肢粗细、眼睛与高光、嘴形、脸颊、耳尾、服装、配件、表面材质和连接结构。
- 三视图只是角色连续性证据，不等于已证明视频模型能够稳定复现；每个实际镜头仍需绑定角色资产并检查漂移。

## 3. 场景、道具与构图

- 使用干净、焦点明确、道具少而有功能的生活或童话场景，保留角色动作区和清楚的前后层级。
- 原木、陶瓷、玻璃、食材、水、泥土等材质应能被视觉和声音共同辨认；不堆放无关装饰。
- 暖色、低饱和、柔和自然光和浅景深仍为基线；季节性颜色可作局部变化，但不破坏系列主色和角色识别。
- 单主角栏目可把“不得出现人手、脸或身体部件”设为项目级纯度锁；这不是整个 Style Profile 的永久禁令。

## 4. 过程叙事与单镜动作

- 延续“一镜一个主要动作、一个主要运镜”。不能把切、倒、搅拌、加热、等待和装盘塞进同一镜头。
- 将过程拆成能看懂因果的微状态：动作前状态 → 主体接近 → 明确接触 → 物体发生反馈 → 角色反应或任务进度变化。
- 对烹饪、手作等多步骤任务，连续追踪：原料/物体形态、数量与位置、使用中的工具、容器、热源或环境状态、角色双手/肢体接触，以及已完成与未完成步骤。
- 每个镜头的结束状态必须能成为下一镜头的起始依据；不得凭空出现成品、瞬间换工具、重复已完成步骤或让食材状态倒退。
- 小动作示例仅是动作词库：低头观察、缓慢靠近、双手抱持、轻轻搅动、等待、触碰、眨眼、耳朵微动。具体动作由当前脚本和道具决定。

## 5. 镜头与节奏

- 可用固定机位、缓慢推进、轻微横移、缓慢后拉、平稳跟拍和轻微上下摇；镜头运动克制、稳定、可预测。
- 禁止同时叠加多重运镜、突然变焦、快速旋转、大幅手持晃动和高频角度乱切。
- 节奏由“平静建立 → 小任务推进 → 感官满足或温柔互动 → 安心停留”组织；具体镜头数、单镜时长、画幅和总时长由当前平台与 Adapter 决定。
- 开场应尽快同时看见角色辨识度、当前小任务和治愈环境，但不把网页声称的固定三秒、八镜或特定完播率写成硬规则。

## 6. 声音：动作可追溯的 ASMR 前景

- 过程型无对白内容优先让同步 ASMR 成为主听觉信息，BGM 只提供低存在感的情绪底色；有对白时，继续以对白可懂度为最高优先级。
- 每个主要拟音必须能回答“什么物体、以什么动作、接触了什么材质”：水流与水花、刀与木砧板、液体微沸、陶瓷轻碰、布料摩擦、柔软成品晃动等只是可替换例子。
- 声音应与接触起点、动作强度、材质和停止时刻同步，并保留短暂的自然衰减；不要用与画面无关的通用“可爱音效”覆盖动作。
- BGM 独立生成、独立混音，不写进视频生成 Prompt；不采用固定 `20%–25%` 或 `70%` 音量数字，实际电平由素材响度、对白和交付平台决定。
- 避免每个镜头自带不同风格的背景音乐、激昂鼓点、声音碎片化和拟音压过角色细表情。

## 7. 连续性与失败判据

### 必须锁定

- 角色主副色、轮廓、比例、五官、高光、服装、配件、耳尾、四肢和材质身份。
- 道具、食材/物体状态、工具、容器、热源、接触关系、场景光线、色调和角色情绪。
- 声音事件与可见动作的来源、材质、起止和强度。

### 失败判据

- 活体软萌角色漂成带缝线、拉链、头套断层或塑料高光的实体玩具。
- 三视图比例、轮廓、五官或材质不一致，无法作为角色绑定资产。
- 单镜出现多个互相争抢的主要动作，或过程状态凭空跳变、倒退、重复。
- 食材/道具、工具、容器、角色接触或场景光线跨镜漂移。
- 拟音不能对应可见声源，BGM 抢占动作细节或对白。
- 为套用治愈风格而删除脚本核心冲突、事实、证据或结论。

## 8. 冲突与生产层边界

- `1:1` 与旧版 `1:1.5–1:2` 不互相替换：前者仅为物件型圆团吉祥物的可选分支，后者保留为动物/类人基线。
- 网页的“纯白三视图、8K、9:16、8 镜、每镜 4–5 秒、运动幅度 2–3”等均是示例或工具配置，不能成为永久 Style Core。
- 豆包、Midjourney、即梦、可灵、剪映及网页提供的具体提示词由当前 Adapter / Prompt Compiler 判断是否适用；本档案不执行网页里的任何命令或工作流。
- 粉丝、点赞、完播率、变现报价、“抚育本能”“内啡肽”等主张未在本任务中验证，不进入 Style Profile 的事实或评分依据。
- IP、角色和品牌引用必须使用用户有权使用的原创或已授权资产；网页中提到的其他账号与知名风格不升级为 Canon。
