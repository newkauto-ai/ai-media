## 0. 解析结论

该文档应归为 **视听 Style Profile + 音乐驱动生产流程**。核心是“先分析已有音乐，再让景别、切镜和空间尺度随低频能量与重复动机递进”，而不是生成某位作曲家的仿作。

### 强适配

- 史诗行进、孤独英雄、文明尺度、战争余波、太空与荒原
- 无旁白、以音乐承担结构的情绪型 MV
- 需要“平静—蓄力—高潮—余韵”递进的短片

### 弱适配

- 依赖对白、口型、字幕解释或复杂事实传达的内容
- 轻松日常、可爱喜剧、以产品信息为主的商业短片
- 音乐没有稳定节拍或段落，却强行要求逐拍快切的项目

## 2. Pre-Content 与音频先导

- 叙事只提供“开端—发展—高潮—余韵”的软结构，不覆盖当前主题。
- 若输入为音乐，先提取 BPM、段落、能量、配器密度、重复动机和情绪转折。
- 若输入只有文字，可生成场景情绪表，但音乐尚未确定的字段必须保持待定。
- 若原始音频含人声，必须先确认是否允许保留；来源同时要求“原音频覆盖全片”和“无演唱”，存在条件冲突。

## 3. 视觉身份

- 写实实拍感，保留皮肤、汗、尘土、锈迹、织物和天气的真实纹理。
- 低饱和、高反差；暗部偏蓝灰，亮部偏琥珀金。
- 逆光剪影、体积雾和可见光束建立尺度感。
- 大远景和全景承担世界尺度，手、脚印、旗帜、武器、灰尘等特写承担情绪触点。
- 轻度胶片颗粒，不使用塑料渲染、卡通、霓虹或过度数字锐化。

## 4. 音画映射

- 低频增强：扩大景别、增加空间纵深、突出逆光剪影或重物运动。
- 中高频上扬：上升运镜、光束显现、视线抬升或空间打开。
- 重复动机：每轮循环至少改变一个维度——景别推进、主体距离、群体规模、切镜频率或光线强度。
- 高潮：切镜更短但仍服从运动方向和光源连续性。
- 余韵：减少运动与切镜，回到大景别或静止细节。

这些是映射原则，不是“某个 BPM 必然对应某种剧情”的机械规则。

## 5. 镜头与剪辑

### 慢节奏沉浸

- 缓慢推拉、水平航拍、摇臂弧线、长焦压缩与轻微呼吸感。
- 单镜可长停留，让环境变化和人物尺度承担张力。

### 快节奏蒙太奇

- 急推、横移、短促手持、Whip Pan 与硬切。
- 快切段落保持同一运动方向和色彩基线，不插入无动机孤立慢镜。

### 连续性

- 同段落主光方向、色温和主体移动方向一致。
- 极端景别跳跃需有中间景别、匹配剪辑或明确黑场。
- 重复场景和人物使用同一视觉锚点。

## 6. 声音系统

- 用户音乐是主时间轴和主 BGM，不在视频片段内重复生成音乐。
- 可选环境声包括风、远雷、低频轰鸣、脚步和战场远声；保持为辅助层。
- 无旁白、无口型同步、无角色演唱；字幕默认关闭。
- 环境声在高潮可短暂增强，在余韵降低，不能遮蔽音乐主体。

## 7. 负面约束

- 不自动复制具体电影、角色或导演镜头
- 不使用卡通、插画、霓虹赛博、塑料 CGI、发光轮廓和 AI 平滑皮肤
- 不把抽象情绪词当成可见画面，必须落到主体、环境、光线和运动
- 不在重复动机段落使用完全不变的静止画面
- 不为追求宏大而让每个镜头都成为大全景

## 8. 来源冲突与降级处理

1. 全局输出写 1080p，但视频生成固定 480p，且未定义可靠超分流程；最终分辨率必须由当前适配器重新确认。
2. 模型失败兜底重复列出同一模型，不构成真实备选方案。
3. 允许最长五分钟音频，但慢镜模式只规定 5–10 镜，无法自然覆盖长音频；镜头数必须按时长与段落重算。
4. 视觉体系借用具体电影人名作为参照；规范化后只保留写实、逆光、尺度、色彩和剪辑特征。
5. 音频既可由用户上传，又声明不含演唱；若原音频有人声，需用户决定，而非静默删除。
