## 2. 风格兼容性

### 强适配

- 机甲、巨兽、巨型生物、超大型工程结构
- 海洋、暴雨、城市灾难、工业基地、末日防线
- 需要恐惧、敬畏、重量和人类渺小感的短片
- 有明确空间、参照物和事件推进的动作叙事

### 弱适配

- 室内人物关系戏、轻喜剧、浪漫日常
- 依赖快速 MV 剪辑而没有尺度建立的内容
- 巨物只作为装饰、没有环境受力反馈的广告片

## 3. 内容前置模块

- 核心主题：人类尺度与不可控巨力、工业文明与原始生物、灾难中的抵抗与余波。
- 推荐结构：预兆 → 局部揭示 → 全貌确认 → 冲突 → 终极压迫 → 余波。
- 每个视听节拍至少推动尺度认知、人类恐惧或环境破坏中的一项。
- 结构是软约束；不能为套“机甲对怪兽”擅自增加第二主角、战斗或毁灭结局。

## 4. 巨物视觉 DNA

### 尺度

- 巨物必须与人、船、车、建筑、维修平台或直升机同框。
- 参照物应保持可辨认，比例差异本身承担叙事功能。
- 环境先建立，巨物再以轮廓、局部、全貌逐步出现。
- 尺度不只靠焦段，还靠遮挡、空气透视、天气层、受力痕迹和声音传播。

### 材质

- 机甲：重工业装甲、液压关节、线缆、制造油迹；战损随剧情阶段递进，不默认全片锈蚀。
- 巨兽：粗糙皮肤、骨刺、黏液、荧光脉络和生物组织；避免光滑卡通表面。
- 场景：混凝土、钢梁、海水、泡沫、雾、暴雨和碎屑保持物理重量。

### 光色与天气

- 灾难暗调、冷色环境、锈铁与局部蓝绿生物光；暖色只作少量对比。
- 光源来自闪电、月光、工厂灯、焊接、机甲眼窗或生物发光。
- 雾用于隐藏和分层，暴雨用于灾难感，海浪用于证明重量；天气必须跨镜连续。
- 禁止无来源发光、明亮商业广告色和糖果色赛博朋克。

## 5. 摄影与剪辑

- 基线：低位仰视、深景深、缓慢后拉、缓慢推进、静止凝视、真实物理震颤。
- 巨物揭示可用地面向上摇起、雾中显露、参照物先入画或水下仰视。
- 冲击瞬间优先让动作在画面内发生，避免用频繁切镜代替重量。
- 灾难混乱才使用明显手持抖动；普通镜头保持摄影机重量感。
- 远景和揭示镜头应给观众足够时间读取尺度；战斗段再加快。
- 默认硬切；时间流逝可叠化；章节可淡入淡出；禁止短视频花式转场。

## 6. 环境反馈与表演

- 巨物行走必须产生浪墙、地面凹陷、结构震动、碎屑或空气位移。
- 动作遵循因果链：施力 → 接触 → 形变 → 传播 → 余波。
- 人类表演服务于尺度认知：仰视、迟滞、失衡、逃离、维修或对视。
- 巨物情绪通过姿态、速度、注视、咆哮、发光变化与环境反应表达，避免拟人化过度。

## 7. 声音与音乐

- 底层：风、海浪、暴雨、雷电、远处低频轰鸣。
- 中层：液压、钢缆、脚步、海水拍击、皮肤摩擦与荧光脉动。
- 顶层：碰撞、结构扭曲、玻璃破裂、建筑倒塌和海啸。
- 巨物出现前可让低频声音先到，建立看不见的尺度。
- 配乐以低频持续音、弦乐、定音鼓、铜管和管弦打击为主；旋律让位于尺度感。
- 余波可回到钢琴、弦乐与自然环境声；背景音乐保持独立音轨。

## 8. 连续性

- 固定巨物配色、发光位置、装甲/皮肤纹理和尺度比例。
- 战损、伤势、天气、浪向、光源方向和参照物位置随剧情有序变化。
- 机甲出厂、轻伤、重伤三个状态不可在同一时间线随机切换。
- 实际生成结果由生产阶段记录，本风格档案只给出预期状态规则。

- 焦段同时出现 14mm、16mm、14–24mm、35mm 和“全局固定”表述，不能全部作为硬规则。
