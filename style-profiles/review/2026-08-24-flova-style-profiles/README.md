## 统一解析规则

1. 区分内容前置、视听与生产三类模块。
2. 不把示例角色、示例剧情、具体作品或参考台词当成固定设定。
3. 具体模型、分辨率、时长、提示词语法、资产格式和暂停节点只进入生产适配层。
4. 缺失字段保持缺失；当前项目建议不能冒充源文档规定。
5. 明确记录源文件路径、SHA-256、抽取模块和抽取方式。
6. 具体创作者、机构、节目或影片名称只保留在来源说明；运行时采用可观察的视听特征。

## 共同风险

- 多份源文档把易变的模型能力写成永久规则，且包含未经当前环境验证的口型、音色、长时一致性和物理参数承诺。
- 多份文档把生成单元时长、最终剪辑镜头时长和故事节拍混为一谈。
- “三视图 + 四宫格”是资产生产策略，不是风格核心；四宫格输入还可能造成最终视频分屏污染。
- 赛博巨物与史诗巨兽主题接近，但前者偏文明层级和赛博社会，后者偏灾难、重量与对抗，不建议直接合并。
- 高能水墨武侠与复合美术动画里的水墨分支定位不同：前者是动作型矿物泼彩，后者是写意留白型，不能互相覆盖。

## 建议的最小下一步

先人工审阅这 7 份 Markdown。确认后只挑实际近期会用的 1–2 个风格档案转成版本化 JSON 并登记注册；不要一次性把全部风格都提升为 `ready`。优先候选：
