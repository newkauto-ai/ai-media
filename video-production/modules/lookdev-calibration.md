# LookDev Calibration

Use exactly the ADP LookDev anchors (3–5) to test the Global Style, Domain Identity, world scale, story usability, and reference usability before batch production. For a mythic Domain, conditionally bind monumental scale, depth, divine/abyssal light, sacred geometry, and coherent impossible architecture; restraint must not collapse into an ordinary costume-drama space.

For each Anchor: compile the type-appropriate executable prompt, request the approved minimum generation set, record AI QA, then request human approval. Only an approved prompt plus approved generated image plus ready Style Profile becomes a reusable Visual Baseline. Mark a failed Domain `domain_blocked`; continue independent approved Domains.
