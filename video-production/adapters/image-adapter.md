# Image Adapter

No image model is configured by default. Before any real call, record the selected Adapter ID/model, supported reference syntax and multi-reference behavior, persistent-context behavior, optics token support, request-parameter support (`size`, `quality`, `background`, `output_format`), known failures, quantity, estimated cost, and stopping condition. Obtain the separate user cost Gate.

The Adapter receives one externally compiled type-specific prompt and the same asset's reviewable call package. It must declare whether each output value is natural-language text or request parameter and whether references are tags, IDs, or request attachments. It cannot assume a prior request supplied identity, style, or product memory. Do not emit exact focal-length labels unless this Adapter has documented and verified support; use visible optics behavior otherwise.

Adapter validation fails if it cannot carry source locks/reference bindings, a mandatory output parameter, or the selected product-evidence truth constraint. Runtime capability never overrides frozen semantic locks or inspected product facts.
